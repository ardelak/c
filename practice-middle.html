01

Починить цикл суммы

Источник: сборник задач, стр. 23, задание 6.

Задание. Проверьте фрагмент for (i = 0, sum = 0; i++, i < 100; sum += i);. Объясните, почему он неверен для суммы первых 100 натуральных чисел, и напишите исправленный вариант.

Замысел решения

Разберите три части заголовка for отдельно. Оператор-запятая в условии сначала меняет i, а точка с запятой после скобок делает тело пустым.

ПОДСКАЗКИ
  • В исходном варианте сложение стоит в части обновления, а не в теле.
  • Проверьте, включается ли число 100 в условие.

05

Разобрать короткое замыкание в присваивании

Источник: сборник задач, стр. 18, задание 3, выражение 3.

Задание. При x=11 и y=-80 вычислите y <<= (x -= 10) && (x -= 11), укажите конечные значения переменных и определите, имеет ли программа гарантированный результат по стандарту C.

Замысел решения

Сначала определите значение левого операнда &&. Если он ненулевой, вычисляется значение всего логического выражения; правый операнд пропускается только при ложном левом.

ПОДСКАЗКИ
  • x -= 10 даёт 1, поэтому правая часть && тоже будет вычислена.
  • После вычисления логического выражения сдвиг на один бит выполняется для отрицательного y.
  • Отделите вычисление операндов от проверки допустимости самого сдвига.
Показать модельное решение на C

Оба операнда && вычисляются: после первого x равно 1, затем становится -10. Значение выражения — 1. Само присваивание y <<= 1 имеет неопределённое поведение, поскольку левый операнд отрицателен.

06

Сравнить выражения с побочными эффектами

Источник: сборник задач, стр. 22, задание 3.

Задание. Для каждого независимого выражения укажите конечные значения переменных или результат: x += (y = 1), y = 2; x ^= (x & y) + 4; x += ((y = 1) || (y = 2)); !x ? x : y; x %= y / 4. Перед каждым выражением заново задаются x=10 и y=20.

Замысел решения

Не переносите изменённые значения из одного пункта в другой: выражения независимы. Учитывайте, что запятая упорядочивает вычисления, а || при истинном левом операнде пропускает правый.

ПОДСКАЗКИ
  • Сначала вычисляйте подвыражение в скобках.
  • Для составного присваивания найдите значение правой части, затем новое значение левой переменной.
  • Составьте отдельную мини-таблицу для каждого выражения.
Показать модельное решение на C

Результаты по порядку: result=2, x=11, y=2; x=14; x=11, y=1; result=20; x=0. В пункте 3 второе присваивание y=2 не выполняется из-за короткого замыкания.

07

Разобрать приоритет побитовых операторов

Источник: сборник задач, стр. 18, задание 3, выражение 2.

Задание. При x=11 и y=-80 вычислите x | (-y ^ 1). Поставьте скобки в соответствии с приоритетом операторов и напишите программу для проверки на GCC.

Замысел решения

Сначала выполняется унарный минус, затем побитовое исключающее ИЛИ ^, после него — побитовое ИЛИ |. Эти операторы не являются логическими операторами.

ПОДСКАЗКИ
  • Запишите выражение как x | ((-y) ^ 1).
  • Вычислите каждую часть в десятичной системе и затем примените побитовые операции.
Показать модельное решение на C

-y равно 80, 80 ^ 1 равно 81, а 11 | 81 равно 91.

08

Проследить static-переменную и указатель

Источник: сборник задач, стр. 15, задание 4.

Задание. Определите вывод программы. Отдельно записывайте значения статической переменной c, локального параметра x и указателя p после каждого вызова f.
int x = 2, y = 1;
int a[3] = { 1, 2 };
int f(int x, int **p) {
    static int c = 2;
    if (c--) **p += x;
    else ++x;
    return (*p)++ - a - x;
}

Замысел решения

Локальная static сохраняет значение между вызовами. Выражение (*p)++ увеличивает сам указатель, а разность указателей на элементы одного массива измеряется в элементах.

ПОДСКАЗКИ
  • Составьте таблицу: номер вызова, c до ветвления, индекс p, массив a, возвращаемое значение.
  • В main есть локальная переменная y, она скрывает глобальную y.
Показать модельное решение на C

Два вызова дают c = -1, затем c = 1; указатель проходит от a[1] к a[2] и a[3]. Поэтому исходный цикл заканчивается с a = {1, 4, 1} и локальным x = 3. Переменная цикла y вне цикла недоступна, поэтому в printf используется глобальное y = 1; печатается 1 4 1 3 1.

Доступ к полям вложенной структуры через указатель

Источник: сборник задач, стр. 20, задание 1, выражение 4.

Задание. Для заданных структур и значений вычислите s.p.x = x + s.n->p.y и перечислите изменённые поля. Затем реализуйте эту операцию в компилируемой программе.

Замысел решения

Поле n — указатель на ту же структуру, поэтому доступ к его полям идёт через ->. Поле p — вложенный объект, к нему обращаются через точку.

ПОДСКАЗКИ
  • Начальное s.p.y равно -20.
  • Порядок вычисления: сначала правая часть присваивания, затем запись в s.p.x.
