Цель урока

Понять, как язык C оценивает логические выражения. В отличие от современных языков, в историческом C нет встроенного логического типа (True/False). Мы детально разберем логические операторы &&, ||, ! и важнейшее для зачетов правило «короткого замыкания» (short-circuit evaluation), которое позволяет писать безопасный код без ошибок сегментации.

Концепция «Истины» и «Лжи» в C

Всё, что не ноль — это истина.

В языке C исторически не было типа bool. Логические операции возвращают целочисленные значения:

  • Ложь (False) всегда представляется как строго 0.
  • Истина (True) в результате логической операции всегда возвращается как 1.
  • Однако, при проверке условий (в if, while) истинным считается ЛЮБОЕ ненулевое значение (1, -5, 100, 3.14, или даже валидный указатель на память).

Логические операторы

Комбинирование условий: И, ИЛИ, НЕ.

Оператор Название Описание
&& Логическое И (AND) Возвращает 1 (истина), если ОБА операнда истинны (не равны нулю). В противном случае возвращает 0.
|| Логическое ИЛИ (OR) Возвращает 1 (истина), если ХОТЯ БЫ ОДИН из операндов истинен. Если оба равны 0, возвращает 0.
! Логическое НЕ (NOT) Унарный оператор (ставится перед переменной). Инвертирует значение: превращает ненулевое значение в 0, а ноль в 1.
ЛОВУШКА ДЛЯ ЭКЗАМЕНАНикогда не путайте логические операторы (&&, ||, !) с побитовыми операторами (&, |, ~). Побитовые операторы работают с битами внутри числа и не имеют механизма «короткого замыкания». Использование & вместо && в условии if — частая причина ошибок, за которую снижают баллы.

Побитовые операторы (Bitwise Operators)

Работа напрямую с битами числа.

В отличие от логических операторов, которые рассматривают всё число целиком как «Истину» или «Ложь», побитовые операторы применяют логическую операцию к каждому отдельному биту двух чисел.

Оператор Название Описание
& Побитовое И (AND) Сравнивает биты. Результат равен 1, только если оба соответствующих бита равны 1. (Часто используется для наложения масок).
| Побитовое ИЛИ (OR) Сравнивает биты. Результат равен 1, если хотя бы один из соответствующих битов равен 1. (Часто используется для установки флагов).
^ Побитовое ИСКЛЮЧАЮЩЕЕ ИЛИ (XOR) Сравнивает биты. Результат равен 1, только если биты разные (один 1, другой 0).
~ Побитовое НЕ (NOT / Инверсия) Унарный оператор. Инвертирует каждый бит числа (0 становится 1, 1 становится 0).
<< / >> Битовые сдвиги Сдвигает все биты влево (умножение на степени двойки) или вправо (целочисленное деление на степени двойки).

Правило короткого замыкания (Short-Circuit Evaluation)

Как C экономит ресурсы и защищает от сбоев.

Правило короткого замыкания (short-circuit evaluation) означает, что компилятор вычисляет логическое выражение слева направо и останавливается сразу же, как только итоговый результат становится гарантированно известен:

  • Для оператора &&: если левый операнд равен 0 (ложь), то всё выражение точно будет ложным. Правый операнд даже не вычисляется!
  • Для оператора ||: если левый операнд истинен (не ноль), то всё выражение точно будет истинным. Правый операнд игнорируется.
ЗАЩИТА ОТ SEGFAULT
Segmentation Fault (Segfault) — это критическая ошибка выполнения, которая происходит, когда программа пытается обратиться к памяти, к которой у неё нет доступа (например, разыменовать NULL-указатель или выйти далеко за границы массива). Операционная система немедленно принудительно завершает такую программу.

Короткое замыкание критически важно для защиты от Segfault. Классический паттерн:
if (ptr != NULL && *ptr == 42) { ... }
Если указатель ptr равен NULL, левое условие ложно. Правое условие (где происходит разыменование *ptr) не выполнится, и программа не упадет. Если бы вы ошибочно использовали побитовое & (у которого нет короткого замыкания), программа попыталась бы вычислить *ptr даже при ptr == NULL и мгновенно упала бы с ошибкой Segfault.

Практические задания для зачета

Задача 1: Високосный год.
Напишите одно логическое выражение внутри условия if, которое определяет, является ли год високосным.
Правило: Год является високосным, если он кратен 4, НО при этом не кратен 100, ИЛИ кратен 400.
Показать ответ к Задаче 1 (фрагмент выражения)

Искомое условие для оператора if:

if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0))

Разбор логики:

  • year % 4 == 0 && year % 100 != 0 — проверка деления на 4 без остатка при условии, что год не вековой.
  • || (year % 400 == 0) — исключение для годов, делящихся на 400 (например, 1600, 2000, 2400 — всегда високосные).
  • Оператор && имеет более высокий приоритет, чем ||, но внешние скобки поставлены для наглядности структуры на зачете.
Задача 2: Безопасный доступ к массиву.
У вас есть массив int arr[5] = {10, 20, 30, 40, 50}; и индекс index, вводимый пользователем. Напишите условие if, которое безопасно проверяет, находится ли индекс в допустимых пределах (от 0 до 4 включительно), и если да, проверяет, больше ли элемент по этому индексу числа 25. Используйте правило короткого замыкания, чтобы избежать обращения к памяти за границами массива (Out of Bounds).
Показать ответ к Задаче 2 (фрагмент выражения)

Искомое условие для оператора if:

if (index >= 0 && index < 5 && arr[index] > 25)

Разбор логики:

  • Сначала мы проверяем, что индекс не отрицательный: index >= 0.
  • Затем проверяем верхнюю границу: index < 5.
  • Только если ОБА эти условия истинны (благодаря короткому замыканию), программа выполнит arr[index] > 25. Это гарантирует, что мы не обратимся к arr[5] или arr[-1], что могло бы вызвать Segfault.
Задача 3: Маскирование битов.
У вас есть переменная unsigned char flags = 0b10101100;. Вам необходимо проверить, установлен ли в единицу третий бит справа (индекс бита 2, так как счет идет с нуля: 0, 1, 2). Напишите выражение внутри if, используя побитовое И (&) и подходящую битовую маску, чтобы вывести сообщение "Бит 2 установлен".
Показать ответ к Задаче 3 (фрагмент выражения)

Искомое условие для оператора if:

if (flags & 0b00000100) { printf("Бит 2 установлен!\n"); }

Или используя сдвиг:

if (flags & (1 << 2)) { printf("Бит 2 установлен!\n"); }

Разбор логики:

  • Маска 0b00000100 имеет единицу только в позиции интересующего нас бита.
  • Побитовое И (&) обнулит все остальные биты переменной flags. Если интересующий бит в flags был равен 1, то результат будет ненулевым (истинным). Если он был равен 0, результат будет 0 (ложным).
Задача 4: Инверсия флага с помощью XOR.
Представьте, что у вас есть переключатель состояний (toggle), представленный переменной int is_active = 1;. Как с помощью одного побитового оператора ИСКЛЮЧАЮЩЕЕ ИЛИ (^) изменить значение переменной на противоположное (с 1 на 0, и с 0 на 1)? Напишите соответствующую короткую строку кода.
Показать ответ к Задаче 4

Решение:

is_active ^= 1;

Разбор логики:

  • Оператор ^ возвращает 1 только если биты разные.
  • Если is_active равно 1: 1 ^ 1 даст 0.
  • Если is_active равно 0: 0 ^ 1 даст 1.
  • Таким образом, выполнение is_active ^= 1; всегда инвертирует младший бит, работая как идеальный переключатель (toggle).
