Цель урока

Понять, как язык C оценивает логические выражения. В отличие от современных языков, в историческом C нет встроенного логического типа (True/False). Мы детально разберем логические операторы &&, ||, ! и важнейшее для зачетов правило «короткого замыкания» (short-circuit evaluation)[cite: 12], которое позволяет писать безопасный код без ошибок сегментации.

Концепция «Истины» и «Лжи» в C

Всё, что не ноль — это истина.

В языке C исторически не было типа bool. Логические операции возвращают целочисленные значения:

  • Ложь (False) всегда представляется как строго 0.
  • Истина (True) в результате логической операции всегда возвращается как 1.
  • Однако, при проверке условий (в if, while) истинным считается ЛЮБОЕ ненулевое значение (1, -5, 100, 3.14, или даже валидный указатель на память).

Логические операторы

Комбинирование условий: И, ИЛИ, НЕ.

Оператор Название Описание
&& Логическое И (AND) Возвращает 1 (истина), если ОБА операнда истинны (не равны нулю). В противном случае возвращает 0.
|| Логическое ИЛИ (OR) Возвращает 1 (истина), если ХОТЯ БЫ ОДИН из операндов истинен. Если оба равны 0, возвращает 0.
! Логическое НЕ (NOT) Унарный оператор (ставится перед переменной). Инвертирует значение: превращает ненулевое значение в 0, а ноль в 1.
ЛОВУШКА ДЛЯ ЭКЗАМЕНАНикогда не путайте логические операторы (&&, ||, !) с побитовыми операторами (&, |, ~). Побитовые операторы работают с битами внутри числа и не имеют механизма «короткого замыкания». Использование & вместо && в условии if — частая причина ошибок, за которую снижают баллы.

Правило короткого замыкания (Short-Circuit Evaluation)

Как C экономит ресурсы и защищает от сбоев.

Правило короткого замыкания (short-circuit evaluation)[cite: 12] — важнейший принцип языка C. Он означает, что компилятор вычисляет логическое выражение слева направо и останавливается сразу же, как только итоговый результат становится гарантированно известен.

  • Для оператора &&: если левый операнд равен 0 (ложь), то всё выражение точно будет ложным. Правый операнд даже не вычисляется!
  • Для оператора ||: если левый операнд истинен (не ноль), то всё выражение точно будет истинным. Правый операнд игнорируется.
ЗАПОМНИТЕ: БЕЗОПАСНАЯ ПРОВЕРКА
Короткое замыкание критически важно для защиты от ошибок сегментации (Segfault). Классический паттерн:
if (ptr != NULL && *ptr == 42) { ... }
Если указатель ptr равен NULL, левое условие ложно. Правое условие (где происходит разыменование *ptr) не выполнится, и программа не упадет! Если бы здесь был побитовый оператор &, программа бы попыталась разыменовать NULL и завершилась аварийно.

Практические задания для зачета

Задача 1: Високосный год.
Напишите одно логическое выражение внутри if, которое определяет, является ли год високосным.
Правило: Год високосный, если он кратен 4, НО при этом не кратен 100, ИЛИ кратен 400.
Задача 2: Безопасный доступ к массиву.
У вас есть массив int arr[5] = {10, 20, 30, 40, 50}; и индекс index, вводимый пользователем. Напишите условие if, которое безопасно проверяет, находится ли индекс в допустимых пределах (от 0 до 4), и если да, проверяет, больше ли элемент по этому индексу числа 25. Используйте правило короткого замыкания, чтобы избежать обращения к памяти за границами массива.
