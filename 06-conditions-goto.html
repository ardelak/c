Цель урока

Освоить инструменты управления потоком выполнения программы (Control Flow). Программа редко выполняется строго линейно — сверху вниз. Чаще всего нам нужно принимать решения на основе данных. Мы разберем классические ветвления (if/else), эффективный выбор из множества опций (switch), лаконичный тернарный оператор (?:) и исторический оператор безусловного перехода goto (и ситуации, когда его использование оправдано).

Условный оператор if / else

Базовое ветвление на основе истинности выражения.

Конструкция if оценивает логическое выражение в скобках. Если оно истинно (не равно нулю), выполняется прикрепленный блок кода. Если ложно (равно нулю) — блок пропускается, либо выполняется альтернативный блок else.

  • Блоки кода { }: Если тело if или else состоит только из одной инструкции, фигурные скобки можно опустить. Однако на зачетах (и в промышленном коде) их рекомендуется ставить всегда, чтобы избежать случайных логических ошибок при добавлении новых строк кода.
  • Каскадирование: Для проверки нескольких взаимоисключающих условий используется связка else if.

Тернарный оператор ( ?: )

Компактная замена простого if / else.

Тернарный оператор — это единственный оператор в C, который принимает три аргумента. Он возвращает одно из двух значений в зависимости от условия.

Синтаксис: условие ? значение_если_истина : значение_если_ложь;

Оператор множественного выбора switch

Эффективная замена длинным цепочкам else if.

Оператор switch используется для сравнения одной переменной с набором константных значений. Это работает быстрее, чем множество if, так как компилятор может оптимизировать switch с помощью "таблиц переходов" (jump tables).

ВАЖНО ДЛЯ ЗАЧЕТА
  1. Тип данных: В круглых скобках switch(выражение) может быть только целое число (int, char, enum). Нельзя использовать double, массивы или строки!
  2. Fall-through (Проваливание): Если после блока case не поставить ключевое слово break;, программа не выйдет из switch, а продолжит выполнять код следующих case подряд, даже если их условия не совпадают! Это частая ловушка.

Безусловный переход goto

Метки и прыжки: когда это зло, а когда спасение.

Оператор goto приказывает компилятору немедленно "прыгнуть" к определенной строке кода, обозначенной меткой (метка:). В академической среде (включая мехмат) goto часто называют абсолютным злом, так как он превращает программу в нечитаемый "спагетти-код".

Однако в языке C есть два классических случая, когда goto считается хорошим тоном:

  1. Единая точка выхода и очистка ресурсов (Clean-up): Если внутри функции произошла ошибка на 5-м шаге из 10, мы прыгаем в конец функции к метке cleanup:, чтобы безопасно закрыть все открытые файлы и освободить память, избегая дублирования кода free() / fclose() в каждом if.
  2. Быстрый выход из глубоко вложенных циклов: Оператор break выходит только из одного (текущего) цикла. Если циклов три, потребуется сложная система флагов. goto решает это в одну строку.

1. При делении (/) обязательно добавьте конструкцию if для защиты от деления на ноль.
