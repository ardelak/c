Как пользоваться уроком

Файлы сохраняют данные после завершения программы. Разберём, как открыть файл, проверить поток, прочитать или записать текст и корректно закрыть файл даже при ошибке.

Каждый блок с именем .c — отдельная полная программа. Сохраните один блок в файл и соберите его, например: gcc -std=c11 -Wall -Wextra file.c -o file. Запускайте программу из папки с входными данными: относительные имена файлов разрешаются относительно текущей рабочей папки процесса, а не обязательно папки с исходным кодом или исполняемым файлом.

Для выполнения примеров используйте отдельную учебную папку: программы создают или перезаписывают файлы students.txt, result.txt и copy.txt.

01

Файл, поток и fopen

Сначала открываем файл, затем работаем с потоком и закрываем его.

Функции для файлов объявлены в <stdio.h>. Вызов fopen("input.txt", "r") открывает текстовый файл и возвращает FILE * — указатель на поток, через который программа читает или записывает данные. Если открыть файл не удалось, возвращается NULL. Доступ к файлу через такой указатель недопустим.

РежимДля чегоЕсли файл уже естьЕсли файла нет
"r"ЧтениеОткрывается для чтения с начала.Открытие не удаётся.
"w"ЗаписьСуществующее содержимое уничтожается при открытии.Создаётся, если это возможно.
"a"ДобавлениеНовая запись идёт в конец файла.Создаётся, если это возможно.

Для чтения и записи через один поток существуют режимы "r+", "w+" и "a+"; при переключении направления работы с ними есть дополнительные правила. В этом уроке используем отдельные потоки и простые режимы из таблицы.

ОСТОРОЖНО: РЕЖИМ "w"Не открывайте нужный существующий файл в режиме "w", если его содержимое нужно сохранить. Очистка происходит при открытии, ещё до первого fprintf.

После работы успешное открытие обязательно завершают вызовом fclose. Он закрывает поток и выполняет необходимую запись буферизованных данных; ошибка записи может обнаружиться только на этом этапе.

02

Запись: fopen, fprintf и fclose

Создадим текстовый файл с двумя записями.

Содержимое students.txt после запуска
Alice 19
Bob 21
  1. fopen создаёт файл или очищает существующий; при ошибке программа сообщает об этом через stderr.
  2. fprintf(out, ...) работает как printf, но записывает в выбранный поток. %s обозначает строку, %d — целое число, \n — конец строки.
  3. Отрицательный результат fprintf означает ошибку записи. Даже при такой ошибке открытый поток нужно закрыть.
  4. fclose возвращает ноль при успехе; ненулевой результат тоже нужно учитывать. После вызова поток закрыт, повторно использовать out нельзя.
ПРОВЕРКАЗапустите программу в отдельной папке и откройте созданный students.txt в текстовом редакторе. Чтобы добавлять записи вместо перезаписи, используйте "a".
03

Чтение текста с помощью fgets

Прочитаем и выведем содержимое файла, созданного предыдущей программой.

Вывод при содержимом файла из примера выше
Alice 19
Bob 21

fgets(line, sizeof line, in) читает до конца строки, конца файла или заполнения буфера: максимум sizeof line - 1 символов, после которых добавляется завершающий '\0'. Если перевод строки прочитан и помещается, он сохраняется в буфере. Последняя строка файла может не содержать \n.

Если строка длиннее буфера, она считывается несколькими фрагментами. Поэтому этот цикл выводит содержимое целиком, но один вызов fgets не всегда соответствует одной полной строке файла. fputs не добавляет собственный перевод строки.

fgets возвращает NULL, если не прочитано ни одного символа из-за конца файла или ошибки; ferror(in) после цикла помогает отличить ошибку чтения от обычного конца файла.

04

Числа из файла: fscanf

Прочитаем два целых числа и запишем их сумму в другой файл.

Создайте в рабочей папке input.txt со значениями 12 30. В этом примере предполагается, что записанные числа представимы в типе int; после чтения дополнительно разрешаются только значения от −1000 до 1000.

Содержимое result.txt
42
  1. fscanf читает из in; каждый %d ожидает целое число и записывает его по переданному адресу &a или &b. Пробелы и переводы строк между числами пропускаются.
  2. Результат — количество успешно присвоенных значений, здесь требуется ровно 2. Может быть и EOF, если ввод закончился или произошла ошибка до первого успешного преобразования.
  3. После проверки чтения и закрытия проверяем количество и диапазон. Благодаря сокращённому вычислению || неисполненные переменные не читаются, когда count != 2.
  4. Только после проверки открываем result.txt, записываем сумму и проверяем запись и закрытие. Значения от −1000 до 1000 дают сумму, представимую в int.
ГРАНИЦА ПРИМЕРАfscanf с %d не является надёжной проверкой очень больших чисел: если введённое значение не представимо в int, поведение не определено. Для произвольного пользовательского ввода читайте текст через fgets и проверяйте преобразование с помощью strtol, включая диапазон и лишние символы. Пример читает только первые два числа и не проверяет оставшийся текст.
05

Посимвольное чтение: fgetc и fputc

Скопируем текст из одного файла в другой до конца потока.

Положите текстовый файл source.txt в рабочую папку. Программа создаст или перезапишет copy.txt; используйте разные имена входного и выходного файлов.

Пример source.txt и получившегося copy.txt
Hello!
File lesson.

fgetc возвращает очередной символ как int либо специальное значение EOF при конце файла или ошибке. Переменная ch имеет тип int, чтобы можно было различить все значения символов и EOF. fputc записывает прочитанный символ и тоже сообщает об ошибке через EOF.

После цикла проверяем ferror(in): нормальный конец файла не является ошибкой. Оба открытых потока закрываются независимо друг от друга; при ошибке выходной файл может остаться неполным.

ТЕКСТОВЫЙ РЕЖИМНа некоторых системах библиотека преобразует окончания строк при чтении и записи текста. Этот пример копирует текст, но не гарантирует побайтовую копию любого файла; для побайтовой работы используют бинарные режимы "rb" и "wb".

Типичные ошибки

ОшибкаПочему это проблемаКак поступить
Не проверять fopenВместо потока может быть NULL.Проверить указатель до любого чтения или записи.
Открыть файл через "w" для чтенияСтарое содержимое уничтожится.Для чтения используйте "r"; для добавления — "a".
Читать в цикле while (!feof(in))Признак конца появляется после неудачной попытки чтения.Проверять результат fgets, fgetc или fscanf.
Сохранить результат fgetc в charМожно потерять возможность корректно отличить символ от EOF.Хранить результат в int.
Считать, что каждый fgets прочитал строку целикомСтрока может быть длиннее буфера.Обрабатывать фрагменты или отдельно собирать длинную строку.
Игнорировать результат записи или fcloseФайл может остаться неполным, даже если предыдущая операция выглядела успешной.Проверять запись и закрытие, сообщать об ошибках.

EOF — признак, возвращаемый функциями ввода при конце потока или ошибке, а не обязательно символ внутри файла. Чтобы выяснить причину после неудачного чтения, используйте ferror; feof сообщает, установлен ли признак конца файла.

07

Самопроверка и практика

Задача 1. В программе записи замените режим "w" на "a" и запустите её два раза. Что произойдёт с записями?
Показать ответ

Каждый запуск добавит две записи в конец файла. Существующее содержимое не будет очищено при открытии.

Задача 2. В файле input.txt содержится только 12. Какое значение вернёт fscanf в примере с суммой и появится ли новый результат?
Показать ответ

Будет присвоено одно значение, поэтому fscanf вернёт 1. Программа сообщит об ошибке и не откроет result.txt; если он уже существовал, прежнее содержимое останется.

Задача 3. Удалите учебный source.txt и запустите программу копирования. Почему выходной файл не открывается?
Показать ответ

fopen в режиме чтения вернёт NULL. Программа сообщит об ошибке и завершится до вызова fopen для copy.txt.

Перед ответом у доски

  • Могу объяснить разницу между "r", "w" и "a".
  • Знаю, что означает FILE * и как проверить открытие файла.
  • Понимаю разницу между чтением числа, фрагмента строки и одного символа.
  • Могу объяснить проверку конца файла, ошибки чтения, записи и закрытия.

Домашняя работа

Три самостоятельные программы: анализ текста, отчёт и обработка данных.

Попробуйте сначала решить каждую задачу самостоятельно. Если застряли, открывайте подсказки по одной: от общей идеи к конкретному шагу. После последней подсказки объясните себе, почему предложенный приём подходит, и продолжайте решение сами.

ОБЩИЕ ТРЕБОВАНИЯДля каждой программы проверяйте открытие файла и результаты необходимых операций; сообщайте об ошибках и завершайтесь с ненулевым кодом. Закрывайте каждый успешно открытый файл и проверяйте fclose. Запускайте программы в отдельной учебной папке, чтобы не потерять важные файлы.
Задача 1. Подвести статистику текста.

В файле notes.txt находится несколько строк английского текста. Длина каждой строки — не более 100 ASCII-символов; последняя строка может не заканчиваться переводом строки. Напишите программу, которая посчитает количество строк и общее количество символов, не считая переводов строк, и выведет оба числа.

notes.txt
Read chapter 14
Try fgets
Done
Ожидаемый вывод
Lines: 3
Characters: 28
Подсказка 1

Откройте файл в режиме "r" и читайте его циклом с помощью fgets, например в массив char line[128].

Подсказка 2

Для каждой прочитанной строки увеличьте счётчик строк. Пройдите по символам до завершающего '\0' и увеличивайте счётчик символов только для тех, которые не равны '\n'.

Подсказка 3

После цикла проверьте ferror, закройте файл и выведите итоговые счётчики. Не вычитайте единицу из длины каждой строки: у последней строки может не быть '\n'.

Проверка себя: почему нельзя определять число символов как размер буфера или всегда уменьшать его на один?

Задача 2. Сформировать отчёт о покупках.

Напишите программу, которая создаёт файл shopping-report.txt. Для каждого товара из примера запишите название, количество, цену за штуку и стоимость всей позиции. В конце добавьте общую стоимость заказа. Данные задайте в программе; если файл отчёта уже существует, замените его содержимое.

Товары и цены
Pen: 4 x 1.50
Notebook: 2 x 3.25
Folder: 3 x 2.00
Содержимое shopping-report.txt после запуска
Product Quantity Price Amount
Pen 4 1.50 6.00
Notebook 2 3.25 6.50
Folder 3 2.00 6.00
Total: 18.50
Подсказка 1

Для создания или перезаписи отчёта используйте режим "w". Для каждой позиции вычислите количество, умноженное на цену.

Подсказка 2

Записывайте строки отчёта с помощью fprintf; для дробной цены подойдёт формат %.2f. Складывайте стоимости позиций в общую сумму.

Подсказка 3

После строк товаров запишите общую сумму. Проверяйте результат каждого fprintf и результат fclose.

Проверка себя: чему равна стоимость каждой позиции и почему нужно проверять ещё и закрытие выходного файла?

Задача 3. Добавить недельную сводку.

В файле steps.txt записаны три целых числа — количество шагов за три дня, каждое от 0 до 100000. Прочитайте их, вычислите сумму и среднее за день, затем добавьте в конец файла weekly.txt строку вида 3 days: total 3600, average 1200.0. Если weekly.txt ещё не существует, создайте его. Считайте, что существующее содержимое weekly.txt заканчивается переводом строки.

steps.txt

weekly.txt до запуска
1 day: total 900, average 900.0
weekly.txt после запуска
1 day: total 900, average 900.0
3 days: total 3600, average 1200.0
Подсказка 1

Прочитайте три числа из steps.txt и убедитесь, что все три успешно получены. Сумму удобно накапливать в переменной типа int.

Подсказка 2

Среднее вычислите как вещественное число, например разделив сумму на 3.0. Для добавления строки в weekly.txt используйте режим "a".

Подсказка 3

Проверьте ошибку чтения и закройте входной файл. Затем запишите сводку через fprintf, добавьте \n, проверьте запись и закройте выходной файл.

Проверка себя: что произойдёт с weekly.txt при повторном запуске и почему стоит открывать его только после успешного чтения данных из steps.txt?

Главное в одном предложении

Выберите нужный режим, проверьте открытие и каждую операцию, а затем закройте все открытые потоки, проверив результат закрытия.
