Константы

Литералы, именованные значения, суффиксы и неизменяемые данные.

Константа задаёт значение, которое программа не должна менять. В C используют литералы, макросы препроцессора, объекты с квалификатором const и константы перечисления.

Способы объявления

  • Макрос #define — текстовая подстановка до компиляции. У макроса нет типа и собственной памяти; компилятор проверяет только результат подстановки.
  • Квалификатор const — типизированный объект, который нельзя изменять через это имя. Он занимает память, а компилятор проверяет тип и попытки записи.
  • enum — именованные целочисленные константы, удобные для связанных состояний, кодов и флагов.

Литералы, системы счисления и суффиксы

Литерал — записанное прямо в исходном коде значение. Его форма определяет тип; суффикс позволяет выбрать тип явно.

ПОРТАТИВНОСТЬЗапись чисел с префиксом 0b поддерживается в C23 и многими компиляторами как расширение. Для более старых стандартов C используйте шестнадцатеричную запись или вычисляйте значение иначе. Восьмеричное число начинается с 0: например, 010 равно 8.
СТРОКОВЫЙ ЛИТЕРАЛСтроковый литерал нельзя изменять. Запись char *s = "text"; сама по себе допустима, но изменение s[0] приводит к неопределённому поведению и может завершиться ошибкой доступа к памяти. Для чтения используйте const char *s.

Квалификатор const и указатели

Место const относительно звёздочки показывает, что именно защищено:

  • const int *ptr (то же, что int const *ptr) — данные нельзя менять через ptr, но сам указатель можно перенаправить.
  • int * const ptr — адрес указателя неизменяем, а значение по этому адресу менять можно.
  • const int * const ptr — нельзя менять ни адрес, ни данные через этот указатель.

Практические задания

Задание 1. Системы счисления и маски.
  1. Подключите <stdint.h> и задайте uint8_t flags = 0b10101100.
  2. Выведите значение в десятичном, восьмеричном и шестнадцатеричном виде с помощью %u, %#o и %#X. Для печати uint8_t передайте в printf приведение к unsigned. Стандартный %#X выводит префикс 0X (заглавная X).
  3. Объявите MASK_EXEC = 0x08 через макрос или enum; проверьте бит выражением flags & MASK_EXEC и выведите ENABLED или DISABLED.
Задание 2. Константная геометрия.
  1. Задайте const double PI = 3.1415926535.
  2. Реализуйте double sphere_volume(const double radius) для формулы V = (4.0 / 3.0) * PI * radius * radius * radius. Вещественное деление важно: 4 / 3 в C равно 1.
  3. Напишите void print_report(const char *label, double value), которая печатает [СФЕРА] <метка>: <значение> с тремя знаками после запятой.
Задание 3. Code review. Отметьте строки, которые не компилируются или приводят к неопределённому поведению, и объясните причину. Какие изменения допустимы?
Ответы к заданию 3
  1. A. Нарушение ограничений: max_score объявлена как const int, присваивать ей новое значение нельзя.
  2. B. Нарушение ограничений: макрос раскрывается в литерал 1.25, которому нельзя присваивать значение.
  3. C. Неопределённое поведение: строковый литерал нельзя изменять. Segmentation fault возможен, но стандартом не гарантирован.
  4. D. Нарушение ограничений: через const int * нельзя изменять значение по указателю.
  5. E. Корректно: указатель на const int может указывать на константный объект.
  6. F. Корректно: адрес const_ptr неизменяем, но значение *const_ptr имеет тип int и может изменяться.
  7. G. Нарушение ограничений: присваивание указателя удаляет квалификатор const у типа, на который он указывает.
ЗАЧЕМ НУЖНО ЭКРАНИРОВАНИЕВ строковом литерале обратная косая черта начинает escape-последовательность: например, \n означает перевод строки, а \t — символ табуляции. Поэтому одиночный слэш в пути нужно записывать как \\, чтобы программа вывела именно \, а кавычку " — как \", иначе она завершит строковый литерал. Апостроф внутри строки в двойных кавычках можно писать напрямую; \' тоже допустимо и обозначает сам апостроф. В задании нужны именно видимые символы \t, а не табуляция: для этого слэш удваивают — \\t. Соседние строковые литералы компилятор склеивает, поэтому длинный путь можно разбить на части для удобства чтения.
Задание 4. Экранирование. Напишите программу, которая выводит ровно одну строку C:\Program Files\"My App"\run.exe -param '\t' и перевод строки после неё. Разбейте путь на две соседние строковые константы; используйте экранирование \\, \" и \'. Последовательность \t должна быть выведена как два символа, а не как табуляция.
