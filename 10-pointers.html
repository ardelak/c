Цель урока

Указатели — это фундаментальная тема языка C и один из главных предметов проверки на зачете. Без глубокого понимания указателей невозможно передавать изменяемые аргументы в функции, работать с массивами, строками и динамической памятью. В этом уроке мы разберем устройство адресации памяти, две разные роли символа *, оператор &, правила безопасной работы с указателями, адресную арифметику и указатели на функции (callbacks).

Концепция адреса и указателя: операторы & и *

Как устроена память и почему символ * имеет два совершенно разных смысла.

Оперативную память компьютера (RAM) можно представить как длинную ленту пронумерованных однобайтовых ячеек. У каждого байта есть свой уникальный номер — адрес памяти (обычно записывается в шестнадцатеричном виде, например 0x7ffd9b8a3abc).

Когда вы объявляете переменную int x = 42;, компилятор выделяет в памяти 4 последовательных байта и записывает туда число 42. Адресом переменной x считается адрес её первого (младшего) байта.

Основные определения

  • Указатель (Pointer) — это переменная, значением которой является адрес другой переменной (или функции) в оперативной памяти.
  • Оператор взятия адреса (&) — унарный оператор, который возвращает адрес переменной в памяти. Выражение &x читается как «адрес переменной x».
  • Оператор разыменования (*, dereference operator) — унарный оператор, применяемый к уже существующему указателю. Он позволяет перейти по хранящемуся в указателе адресу и прочитать или изменить лежащее там значение.
НЕ ПУТАЙТЕ ДВЕ РОЛИ ЗВЁЗДОЧКИ (*)

В языке C символ * действительно имеет два разных смысла в зависимости от контекста:

  1. В объявлении переменной: int *p = &x; — здесь звёздочка является частью типа (int * — «указатель на int»). Она говорит компилятору, что p хранит адрес, а не само целое число.
  2. В выражениях (инструкциях кода): *p = 99; — здесь звёздочка работает как команда разыменования («пройди по адресу, записанному в p, и положи в ту ячейку число 99»).

Роль 1: звёздочка в объявлении

Здесь:

  • &x — адрес переменной x в памяти;

При объявлении звёздочку можно писать как слитно с типом, так и слитно с именем переменной — обе записи означают одно и то же (p имеет тип int *):

ВАЖНЫЙ НЮАНС ОБЪЯВЛЕНИЯ НЕСКОЛЬКИХ ПЕРЕМЕННЫХ

В строке int *a, b; указателем будет только a, а b окажется обычной переменной типа int! Звёздочка относится к конкретному имени переменной, а не ко всей строке. Поэтому гораздо понятнее и безопаснее объявлять указатели на отдельных строках:

int *a;
int b;

Роль 2: звёздочка как разыменование

Когда * стоит не в объявлении, а перед именем уже существующего указателя в выражении, она означает операцию разыменования (dereference): «возьми адрес из p и обратись к значению по этому адресу».

Здесь *p — это не сам указатель, а значение, на которое он указывает, то есть сама переменная x.

Полный пример и схема памяти

Схема в памяти после выполнения *p = 99
x  ┌──────────┐
   │    99    │  ← значение (тип int)
   └──────────┘
      ▲
      │ указывает по адресу
p  ┌──────────┐
   │   &x     │  ← указатель хранит адрес переменной x (тип int *)
   └──────────┘

Как быстро различать смысл звёздочки

Код Контекст Что означает *
int *p; Объявление p — переменная-указатель на тип int.
int *p = &x; Объявление с инициализацией Указатель p создаётся и сразу сохраняет адрес переменной x.
y = *p; Выражение (справа от =) Прочитать значение, лежащее в памяти по адресу из p.

printf("%d", *p); Выражение (аргумент функции) Передать в printf целое значение, на которое указывает p.
ПОЛЕЗНОЕ ПРАВИЛО ЧТЕНИЯ

В объявлении int *p; можно читать как: «если разыменовать p (написать *p), получится тип int». А после объявления во всех выражениях *p — это уже сама переменная x, доступ к которой идёт через её адрес.

Две частые ошибки новичков на зачете

ИТОГОВОЕ ПРАВИЛО

Запомните короткую формулу: p — это «адрес», а *p — «то, что лежит по этому адресу».

Передача параметров в функции по адресу

Как изменить переменные вызывающей функции и вернуть сразу несколько значений.

Как мы изучили в уроке 08, в языке C все аргументы передаются в функции строго по значению (pass by value) — функция получает локальную копию аргумента. Однако, если передать в функцию адрес переменной (указатель), функция получит копию адреса, сможет разыменовать его через * и напрямую изменить оригинальную переменную в вызывающем коде (например, в main).

Разбор классической функции swap и возврата результата через указатель

Именно по этой причине функция scanf("%d", &val) требует знак амперсанда &: чтобы записать прочитанное с клавиатуры число в вашу переменную val, функция scanf должна знать её адрес в памяти!

ЗАПОМНИТЕ ПРАВИЛО ВЫЗОВА И ВНУТРЕННЕЙ РАБОТЫ

Когда вы пишете вызов функции в main, вы передаете адрес переменной через &: safe_divide(15.0, 4.0, &res);.
Когда вы пишете тело самой функции, параметр double *result уже является указателем. Чтобы записать в него число, вы используете разыменование *: *result = num / den;.

Безопасность указателей: NULL, висячие указатели и const

Как избежать неопределенного поведения (UB) и падения программы с Segmentation Fault.

Неправильная работа с указателями — главная причина аварийного завершения программ на C. На зачете преподаватели особенно внимательно проверяют три типа опасных указателей:

  • Дикий (неинициализированный) указатель (Wild Pointer): Указатель, объявленный без начального значения (int *p;). Он содержит случайный «мусорный» адрес со стека. Попытка чтения или записи *p = 5; приводит к Undefined Behavior (UB) и крушению программы.
  • Нулевой указатель (NULL): Специальная константа (из <stddef.h> или <stdio.h>), гарантирующая, что указатель «никуда не указывает». Если у вас пока нет адреса для указателя, всегда инициализируйте его значением NULL. Разыменовывать NULL нельзя — поэтому перед использованием указателя его проверяют условием if (p != NULL).
  • Висячий указатель (Dangling Pointer): Указатель, который продолжает хранить адрес уже уничтоженной переменной (например, адрес локальной переменной функции, которая уже завершила работу, или памяти после free()).

Квалификатор const и указатели

Чтение объявлений с const и * легко освоить, если смотреть, по какую сторону от звёздочки * стоит слово const:

  • const int *p (или int const *p) — указатель на константные данные. Через p нельзя менять число (*p = 10 запрещено), но сам указатель можно перенаправить на другую переменную (p = &other разрешено). Используется для входных массивов в функциях!
  • int * const p = &x — константный указатель. Он навсегда привязан к адресу &x (p = &other запрещено), но само число менять можно (*p = 10 разрешено).
  • const int * const p = &x — константный указатель на константные данные. Нельзя менять ни адрес, ни значение по адресу.

Массивы и адресная арифметика

Почему имя массива — это адрес первого элемента, и как работает сложение указателя с числом.

В языке C массивы и указатели тесно связаны. Элементы массива располагаются в памяти строго подряд (непрерывно). В большинстве выражений имя массива автоматически преобразуется (decay) в указатель на его первый (нулевой) элемент: arr == &arr[0].

Правила адресной арифметики

  1. Сложение и вычитание с целым числом (p + i, p - i, p++, p--): Прибавление единицы к указателю p + 1 увеличивает хранящийся в нём байтовый адрес не на 1 байт, а ровно на sizeof(*p) байт! То есть для int *p (где sizeof(int) == 4) выражение p + 1 сдвигает указатель ровно на 4 байта вперёд — сразу на следующий элемент массива.
  2. Фундаментальное тождество индексации: Запись arr[i] для компилятора C — это просто сокращённый синтаксический сахар для выражения *(arr + i) («сдвинься от начала массива на i элементов и разыменуй адрес»).
  3. Разность двух указателей (p2 - p1): Если два указателя указывают на элементы одного и того же массива, их можно вычесть друг из друга. Результатом (тип ptrdiff_t) будет количество элементов между ними, а не количество байт!
  4. Сравнение указателей (<, >, ==, !=): Позволяет проверять, какой элемент массива расположен раньше или дошел ли бегущий указатель до конца массива.
ЛОВУШКА: sizeof МАССИВА ВНУТРИ ФУНКЦИИ

Внутри функции main, где объявлен массив int arr[10];, оператор sizeof(arr) вернет размер всего массива в байтах (40). Но если вы передадите arr в функцию void foo(int arr[]), то внутри foo параметр arr является обычным указателем int *, и sizeof(arr) вернет размер указателя (8 байт)! Поэтому размер массива всегда передается в функцию отдельным параметром int n.

Указатели на функции и Callbacks

Как передать одну функцию внутрь другой или создать массив функций.

Машинный код любой функции также размещается в оперативной памяти (в сегменте кода), а значит, у каждой функции есть свой адрес. В C можно создать указатель на функцию, сохранить в него адрес функции, передавать его как аргумент в другие функции (механизм callback — функции обратного вызова) или хранить в массиве.

Синтаксис объявления

Объявление указателя на функцию повторяет её прототип, где вместо имени функции в круглых скобках пишется (*имя_указателя):

возвращаемый_тип (*имя_указателя)(типы_параметров);

Круглые скобки вокруг (*fp) обязательны! Без них запись int *fp(int, int); будет означать прототип функции fp, возвращающей указатель int *.

СОВЕТ ДЛЯ ЗАЧЕТА

При передаче функции в качестве аргумента (например, apply(add, 5, 6) или qsort(..., compare_ints_asc)) никогда не ставьте круглые скобки после её имени! Имя функции без скобок — это её адрес. Если поставить скобки, компилятор попытается вызвать функцию прямо на месте.
