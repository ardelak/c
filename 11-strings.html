Раздел I

Часть 1. Устройство строк в памяти и библиотека <string.h>

Чек-лист перед практикой

  • Что такое строка в C: это массив типа char, который обязательно завершается нуль-терминатором (символом '\0' с числовым кодом 0).
  • Правило N + 1 байт: для хранения слова из N видимых букв массив должен иметь размер минимум N + 1 байт (1 байт под '\0').
  • Массив vs Указатель на литерал: изменяемый массив char arr[] = "msu"; лежит на стеке и допускает замену символов (arr[0] = 'M';). Строковый литерал через указатель const char *p = "msu"; указывает на память только для чтения — попытка изменить p[0] приводит к ошибке сегментации (Segmentation Fault).
  • Сравнение строк: строки нельзя сравнивать оператором == (он сравнивает только адреса массивов в памяти, а не их текст!). Для сравнения используется strcmp(s1, s2) == 0.
  • Функции <string.h> и <stdio.h>: strncpy (копирование n байт, терминатор '\0' ставим вручную!), strncat (склейка с ограничением длины), strcmp / strncmp (посимвольное сравнение), strchr (поиск символа), strstr (поиск подстроки), strtok (разбивка на токены), snprintf (безопасная форматированная запись в буфер с гарантированным '\0').
  • Вложенный printf: вызов printf("%d", printf("msu")) выводит msu3 — внутренний printf печатает текст и возвращает число выведенных символов (3), которое затем печатает внешний printf.

Как устроена строка в памяти: нуль-терминатор '\0'

Правило N + 1 байт, разница между sizeof и strlen, изменяемый массив против литерала.

В языке C нет встроенного типа string. Си-строка (null-terminated string) — это обычный массив элементов типа char, расположенных в памяти подряд, конец которого помечен специальным байтом '\0' (его ASCII-код равен 0).

Зачем нужен символ '\0'?

Когда вы передаёте строку в функцию (например, в printf("%s", s) или strlen(s)), функция получает только адрес первого символа (char *). Размер массива ей неизвестен! Функция просто шагает по байтам вперёд, пока не наткнётся на байт '\0' — это сигнал «стоп, строка закончилась».

Представление строки "Hello" в памяти (5 букв = 6 байт!)
Индекс:     [0]    [1]    [2]    [3]    [4]    [5]
           ┌──────┬──────┬──────┬──────┬──────┬──────┐
Символ:    │ 'H'  │ 'e'  │ 'l'  │ 'l'  │ 'o'  │ '\0' │
           ├──────┼──────┼──────┼──────┼──────┼──────┤
Код ASCII: │  72  │ 101  │ 108  │ 108  │ 111  │   0  │
           └──────┴──────┴──────┴──────┴──────┴──────┘

Отсюда следует железное правило: чтобы сохранить строку из N видимых символов, массив должен иметь размер минимум N + 1 байт.

НЕ ПУТАЙТЕ '0' И '\0', А ТАКЖЕ 'A' И "A"

1. Цифра '0' vs Нуль-терминатор '\0': символ печатного нуля '0' имеет код ASCII 48, а нуль-терминатор '\0' имеет код 0 (то есть в C выражение '\0' == 0 истинно!).
2. Одинарные кавычки 'A' vs Двойные "A":
• 'A' — это символьный литерал (целое число 65 типа int, занимает 4 байта).
• "A" — это строковый литерал, то есть массив из 2 байт: {'A', '\0'}!

Изменяемый массив (char arr[]) vs Строковый литерал (const char *)

  1. Массив на стеке: char arr[] = "Hello"; — создаёт массив в вашей локальной памяти (на стеке) и копирует туда все 6 байт. Символы можно менять: arr[0] = 'M';.
  2. Указатель на литерал: const char *ptr = "Hello"; — сама строка "Hello\0" лежит в защищённой области памяти только для чтения (read-only). Попытка выполнить ptr[0] = 'M'; вызовет Segmentation Fault!

Функции копирования, конкатенации и форматирования

strncpy, strncat и snprintf: как работать с буферами без выхода за границы.

Массивы в C нельзя копировать оператором = (нельзя написать dst = src;). Для записи текста в массив-буфер мы используем стандартные функции:

Функция Как работает и о чём нужно помнить на зачете
strncpy(dst, src, n) Копирует не более n байт из src в dst. Ловушка: если длина src больше или равна n, функция не запишет '\0'! Поэтому всегда вызываем с sizeof(dst) - 1 и принудительно ставим dst[sizeof(dst) - 1] = '\0';.
strncat(dst, src, n) Находит конец строки в dst (где стоит '\0'), дописывает туда не более n символов из src и всегда ставит '\0' в конец. Чтобы не переполнить dst, передавайте остаток места: sizeof(dst) - strlen(dst) - 1.
snprintf(buf, size, fmt, ...) Самый удобный и безопасный способ: форматирует любые данные (числа, строки) по шаблону fmt прямо в массив buf размера size. Никогда не пишет за пределы size и всегда гарантирует '\0'!

Сравнение, поиск и разбиение строк на токены

strcmp / strncmp, strchr, strstr и strtok.

ПОЧЕМУ НЕЛЬЗЯ ПИСАТЬ if (s1 == s2)?

Имена массивов s1 и s2 в выражении преобразуются в указатели (адреса их первых байтов). Оператор s1 == s2 проверяет, совпадают ли адреса в памяти, а не буквы! Два разных массива в памяти всегда имеют разные адреса, поэтому s1 == s2 даст 0 (ложь), даже если в обоих написано "msu".

Шпаргалка по strcmp(s1, s2) и strncmp(s1, s2, n)

Функция strcmp идёт по двум строкам одновременно и сравнивает ASCII-коды символов до первого несовпадения (а strncmp сравнивает максимум первые n символов):

  • strcmp(s1, s2) == 0 — строки абсолютно равны (Внимание: 0 в C означает «ложь», поэтому никогда не пишите if (strcmp(a, b)) для проверки равенства — всегда явно пишите == 0!).
  • strcmp(s1, s2) < 0 — первая строка s1 лексикографически (по алфавиту / ASCII) меньше второй (например, "abc" и "abd").
  • strcmp(s1, s2) > 0 — первая строка s1 больше второй.

Поиск (strchr, strstr) и токенизация (strtok)

  • strchr(s, ch) — возвращает указатель на первое вхождение символа ch в строке s (или NULL, если символа нет). А функция strrchr(s, ch) ищет последнее вхождение символа (справа).
  • strstr(haystack, needle) — возвращает указатель на начало подстроки needle внутри строки haystack (или NULL).
  • strtok(str, delim) — разрезает изменяемый массив str на слова (токены), заменяя символы-разделители из delim прямо в памяти на '\0'! Первый вызов: strtok(str, delim), последующие вызовы в цикле: strtok(NULL, delim).

Чтение строк с пробелами (fgets) и библиотека <ctype.h>

Как правильно считывать строки с клавиатуры и классифицировать символы.

Почему на зачете лучше использовать fgets вместо scanf("%s")?

Вызов scanf("%s", buf) читает ввод только до первого пробела! Если ввести "Hello world", в buf попадёт только "Hello". Чтобы прочитать всю строку целиком (вместе с пробелами) и гарантированно не выйти за границы массива, используют функцию fgets:

fgets(buf, sizeof(buf), stdin);

Важная тонкость: когда пользователь нажимает клавишу Enter, fgets записывает символ перевода строки '\n' внутрь буфера перед '\0' (например, "Hello\n\0"). Чтобы избавиться от этого '\n', используют стандартную идиому с функцией strcspn (она находит индекс первого появления '\n' и мы заменяем его на '\0'):

buf[strcspn(buf, "\n")] = '\0';

ПРАВИЛО БЕЗОПАСНОСТИ: ПРИВОДИТЕ АРГУМЕНТ К (unsigned char)

Тип char по умолчанию часто знаковый (от -128 до 127). Если в функции isalpha или tolower передать отрицательный код символа, возникнет неопределённое поведение (UB). Поэтому при вызове функций из <ctype.h> символ приводят к (unsigned char): isdigit((unsigned char)*p).
