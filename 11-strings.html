Цель урока

В языке C нет встроенного примитивного типа string, как в Python или C++. Строка в C — это обычный массив символов char, который обязательно заканчивается специальным нулевым байтом '\0'. Задачи на строки проверяют умение работать с массивами, указателями, циклами и памятью. В этом уроке мы разберем внутреннее устройство строк, стандартную библиотеку <string.h>, обработку символов <ctype.h> и напишем собственные строковые алгоритмы.

Как устроена строка в памяти: нуль-терминатор '\0'

Массив символов, разница между sizeof и strlen, массив против указателя на литерал.

Си-строка (C-string / null-terminated string) — это последовательность символов типа char, расположенная в непрерывной области памяти и завершающаяся нуль-терминатором (символом '\0' с целочисленным кодом 0).

Зачем нужен символ '\0'?

Когда вы передаете строку в функцию (например, в printf("%s", s) или strlen(s)), функция получает лишь указатель char * на первый символ. Она не знает размер массива! Единственный способ понять, где строка заканчивается — идти по байтам вперед, пока не встретится байт со значением '\0'.

Представление строки "Hello" в памяти (6 байт!)
Индекс:     [0]    [1]    [2]    [3]    [4]    [5]
           ┌──────┬──────┬──────┬──────┬──────┬──────┐
Символ:    │ 'H'  │ 'e'  │ 'l'  │ 'l'  │ 'o'  │ '\0' │
           ├──────┼──────┼──────┼──────┼──────┼──────┤
Код ASCII: │  72  │ 101  │ 108  │ 108  │ 111  │   0  │
           └──────┴──────┴──────┴──────┴──────┴──────┘

Из этой схемы вытекает важнейшее правило: чтобы сохранить строку из N видимых символов, массив должен иметь размер минимум N + 1 байт (один дополнительный байт под '\0').

Два способа создать строку: изменяемый массив vs строковый литерал

На этом различии строится один из самых частых вопросов на зачете:

  1. Массив на стеке: char arr[] = "Hello"; — компилятор выделяет на стеке массив из 6 байт и копирует туда символы 'H','e','l','l','o','\0'. Эти символы принадлежат вам, их можно изменять (например, arr[0] = 'M';).
  2. Указатель на строковый литерал: const char *ptr = "Hello"; — сама строка "Hello\0" размещается в специальной секции памяти программы только для чтения (read-only data / .rodata), а указатель ptr просто хранит её адрес. Попытка изменить символ ptr[0] = 'M'; приведет к Undefined Behavior и падению программы с Segmentation Fault! Поэтому указатели на литералы всегда следует объявлять с квалификатором const.
Вывод
Измененный массив: Mello
mutable_str: strlen = 5, sizeof = 6 (5 букв + 1 байт под '\0')
buffer[32]:  strlen = 5, sizeof = 32 (длина текста 5, но буфер на 32 байта)
literal_ptr: strlen = 5, sizeof = 8 (sizeof вернул размер указателя!)
ЛОВУШКА: ОДИНАРНЫЕ И ДВОЙНЫЕ КАВЫЧКИ

В языке C 'A' и "A" — это совершенно разные типы данных!
• 'A' — это символьная константа (целое число — ASCII-код 65, тип int).
• "A" — это строковый литерал (массив из двух байт: {'A', '\0'}, который в выражениях превращается в указатель char *).

Копирование, конкатенация и форматирование строк

Почему строки нельзя присваивать через = и как избежать переполнения буфера.

Поскольку строка в C — это массив, к ней нельзя применить оператор присваивания = после объявления (запись char a[10], b[10] = "Hi"; a = b; не скомпилируется, так как нельзя присвоить один массив другому). Для копирования и склеивания строк используются функции из заголовочного файла <string.h>.

Функция Назначение и особенности безопасности
strcpy(dst, src) Копирует строку src (включая '\0') в буфер dst. Опасно: не проверяет размер буфера dst! Если src длиннее, произойдет переполнение буфера (Buffer Overflow).
strncpy(dst, src, n) Копирует не более n байт из src в dst. Нюанс: если в первых n байтах не встретился '\0', функция не поставит '\0' в конец dst! Поэтому после неё всегда вручную ставят терминатор: dst[sizeof(dst) - 1] = '\0';.
strcat(dst, src) Дописывает (конкатенирует) строку src в конец строки dst, перезаписывая старый '\0' строки dst и ставя новый в конце. Требует, чтобы в dst хватило свободного места!
strncat(dst, src, n) Безопасная версия: дописывает в конец dst не более n символов из src и всегда добавляет завершающий '\0'. Обычно вызывается как strncat(dst, src, sizeof(dst) - strlen(dst) - 1).
snprintf(buf, size, fmt, ...) Золотой стандарт безопасности в современном C (из <stdio.h>): работает как printf, но записывает результат в строковый буфер buf размера size. Никогда не выходит за границы буфера и всегда гарантирует наличие '\0' в конце!

Сравнение строк, поиск и разбиение на токены

Функции strcmp, strchr, strstr и strtok из <string.h>.

ГЛАВНАЯ ЛОВУШКА НА ЗАЧЕТЕ: ОПЕРАТОР == ДЛЯ СТРОК

Никогда не сравнивайте строки через if (str1 == str2)! В языке C имена массивов в выражении преобразуются в указатели (адреса их первых элементов). Поэтому выражение str1 == str2 сравнивает адреса в памяти (лежат ли две строки в одной и той же ячейке), а не их текст! Два разных массива с одинаковым текстом "abc" имеют разные адреса, и str1 == str2 вернет 0 (ложь).

Лексикографическое сравнение: функция strcmp

Функция int strcmp(const char *s1, const char *s2) посимвольно сравнивает коды символов двух строк до первого различия или до '\0':

  • Возвращает 0, если строки абсолютно одинаковы (주의: 0 в C — это «ложь», поэтому для проверки равенства пишут if (strcmp(s1, s2) == 0)!).
  • Возвращает число < 0, если строка s1 по алфавиту (по кодам ASCII) идет раньше s2 (например, "abc" и "abd").
  • Возвращает число > 0, если строка s1 идет позже s2.

Поиск символа, подстроки и разбиение на слова

  • char *strchr(const char *s, int c) — ищет первое вхождение символа c в строке s. Возвращает указатель на найденный символ внутри строки (или NULL, если символа нет). Чтобы узнать индекс найденного символа, вычтите из найденного указателя начало строки: p - s!
  • char *strstr(const char *haystack, const char *needle) — ищет первое вхождение подстроки needle в строке haystack. Возвращает указатель на начало найденной подстроки или NULL.
  • char *strtok(char *str, const char *delim) — разбивает строку на части (токены), разделенные любым из символов-разделителей из delim. Важно: strtok изменяет исходную строку (ставит '\0' на место разделителей), поэтому ей нельзя передавать строковый литерал! При первом вызове ей передают саму строку, а при всех последующих в цикле — NULL.

Безопасный ввод строк и посимвольная обработка (<ctype.h>)

Чтение строк с пробелами через fgets и функции классификации символов.

Почему scanf("%s") опасен и неудобен для строк?

Функция scanf("%s", buf) имеет два серьезных недостатка: во-первых, она читает текст только до первого пробела (не может прочитать предложение из нескольких слов); во-вторых, без указания ширины она легко переполняет буфер. Поэтому на практике и на зачетах для чтения строки целиком используют функцию fgets:

fgets(buf, sizeof(buf), stdin);

Она читает не более sizeof(buf) - 1 символов до нажатия Enter. Единственная особенность: если места хватило, fgets сохраняет в конец строки сам символ перевода строки '\n'. Его легко удалить в одну строчку с помощью функции strcspn (которая возвращает индекс первого вхождения любого символа из второго аргумента):

buf[strcspn(buf, "\n")] = '\0';

Библиотека <ctype.h> для работы с отдельными символами

Вместо того чтобы вручную проверять коды ASCII (вроде c >= '0' && c <= '9'), в стандартной библиотеке <ctype.h> есть готовые быстрые функции:

  • isalpha(c) — буква (a-z, A-Z);
  • isdigit(c) — цифра (0-9);
  • isalnum(c) — буква или цифра;
  • isspace(c) — любой пробельный символ (пробел ' ', табуляция '\t', перевод строки '\n', возврат каретки '\r');
  • isupper(c) / islower(c) — заглавная / строчная буква;
  • toupper(c) / tolower(c) — переводит букву в верхний / нижний регистр (остальные символы возвращает без изменений).
ВАЖНОЕ ПРАВИЛО СТАНДАРТА C: ПРИВЕДЕНИЕ К (unsigned char)

На большинстве платформ базовый тип char является знаковым (от -128 до 127). Если в строке встретится символ с кодом больше 127, значение char будет отрицательным, а передача отрицательного числа (кроме EOF) в функции <ctype.h> вызывает неопределенное поведение (UB). Поэтому по стандарту C аргумент всегда приводят к (unsigned char): например, toupper((unsigned char)s[i]).
