Практикум: закрываем пробелы

Циклы, вычисления, строки и указатели — с опорой на пройденные темы

Почему выбраны эти задачи

В конспектах последних занятий повторяются три точки для практики: самостоятельно нормализовать и изменять строки; аккуратно вести границы циклов и накопление суммы; объяснять вычисления с остатком, инкрементом и побочными эффектами. Ранее также отмечалась ошибка в сумме массива и необходимость вынести итоговую проверку поиска за пределы цикла.

Поэтому задания 1–7 возвращают к циклам, индексам, строкам и чтению выражений. Задания 8–10 — усложнение на массивы, рекурсию и анализ состояния указателей. Последние два можно оставить на самостоятельную работу.

Практикум составлен по темам и трудностям, отмеченным в конспектах занятий; задания адаптированы для повторения и самостоятельного объяснения решения.

Как проходить практикум

  1. Перед кодом запишите входные данные, состояние переменных и условие остановки.
  2. После кода проверьте обычный пример и хотя бы один граничный случай.
  3. Для каждой задачи объясните, почему цикл не выходит за границы и где обновляется результат.
  4. Если в выражении поведение не определено стандартом C, так и отметьте — не подбирайте «ожидаемый» вывод.

Критерий готовности: решение компилируется с предупреждениями -Wall -Wextra, проходит ваши тесты и может быть объяснено без чтения готового решения.

01

Починить цикл суммы основа

Задание. Верно ли решена задача «найти сумму первых 100 натуральных чисел»? Если неверно — объясните почему. 
for (i = 0, sum = 0; i++, i < 100; sum += i)
    ;
Подсказка Составьте таблицу значений счётчика для первой и последней итераций. Проверьте, где именно выполняется сложение и включено ли число 100.
Показать модельное решение

В исходном фрагменте тело цикла пустое из-за точки с запятой. Счётчик увеличивается в условии, а сложение в обновлении выполняется только после успешной проверки; поэтому суммируются 1–99, без 100. Проще сделать все три действия явными:

int sum = 0;

for (int i = 1; i <= 100; ++i) {
    sum += i;
}

Цикл выполняет тело 100 раз; итоговая сумма — 5050.

Проверка: назовите, сколько раз выполнится тело цикла и какое значение счётчика завершит его.

02

Посчитать пары разной чётности основа

Задание. С использованием единственного цикла for напишите фрагмент программы, который для массива int a[N] формирует в переменной pairs количество пар соседних элементов, имеющих разную чётность. Другие операторы циклов и операторы перехода использовать запрещено.
Подсказка Пара начинается в позиции i и использует также i + 1. Сначала определите последнюю допустимую позицию начала пары; затем инициализируйте счётчик до цикла.
Показать модельное решение на C 
int count_parity_changes(const int a[], int n)
{
    int pairs = 0;

    for (int i = 0; i + 1 < n; ++i) {
        int first_is_even = a[i] % 2 == 0;
        int second_is_even = a[i + 1] % 2 == 0;
        if (first_is_even != second_is_even) {
            ++pairs;
        }
    }

    return pairs;
}

Проверяются ровно n - 1 соседних пар. Сравнение булевых признаков чётности работает и для отрицательных значений.

Проверьте: массивы длины 0 или 1, а также отрицательные числа. У отрицательных чисел остаток % 2 может быть равен -1, поэтому сравнивайте признаки чётности, а не только остаток с единицей.

03

Накопить скалярное произведение основа

Задание. Напишите функцию int scalar(void), которая считывает со стандартного потока ввода непустую последовательность целых чисел, заканчивающуюся нулём. Ноль не входит в последовательность; количество ненулевых элементов чётно, элементы нумеруются с 1. Функция возвращает скалярное произведение двух векторов: первый составлен из элементов с нечётными номерами, второй — из элементов с чётными номерами. Разрешено использовать не более одного оператора цикла; операторы перехода запрещены.
Подсказка Элемент с нечётным номером — первый компонент очередной пары, элемент со следующим чётным номером — второй. Храните первый компонент, пока не считаете второй; после добавления произведения сбрасывайте состояние ожидания и переходите к следующей паре. Ноль завершает ввод и не должен участвовать в произведении.
Показать модельное решение на C 
#include <stdio.h>

int scalar(void)
{
    int value;
    int first = 0;
    int have_first = 0;
    int sum = 0;

    while (scanf("%d", &value) == 1 && value != 0) {
        if (!have_first) {
            first = value;
            have_first = 1;
        } else {
            sum += first * value;
            have_first = 0;
        }
    }

    return sum;
}

Флаг показывает, ожидает ли алгоритм первый или второй элемент пары. Для ввода 2 3 4 5 0 результат равен 2*3 + 4*5 = 26. Предполагается, что поток содержит корректную последовательность и сумма помещается в int.

Проверьте: минимальную допустимую последовательность из двух чисел, несколько пар и последовательность, где один из компонентов отрицательный.

04

Разобрать побочные эффекты выражений основа

Задание. Пусть int x = 42; и int y = -105;. Для каждого из шести независимых выражений укажите его значение и побочные эффекты, если они есть, либо напишите «ошибка», если выражение ошибочно. 
1) y %= x / 5
2) x ^ ~y & 65
3) y <<= (--x || --y)
4) (y = 1) && (y = 2)
5) x++ + --y
6) x += y, y = x - y, x -= y
Подсказка Каждое выражение начинается заново с x = 42, y = -105. Для ++ и -- отдельно отмечайте значение выражения и изменение переменной; для && и || проверяйте короткое замыкание; оператор-запятая выполняет части слева направо. Побитовые операции группируйте по приоритету. Если выражение нарушает требования языка C, не выводите результат по тому, что случайно напечатал один компилятор.
Показать модельное решение
  1. x / 5 равно 8; -105 % 8 равно -1. Результат -1; после выражения x = 42, y = -1.
  2. При представлении отрицательных чисел в дополнительном коде: ~(-105) = 104, 104 & 65 = 64, 42 ^ 64 = 106. Значение — 106; переменные не меняются. Результат для отрицательного знакового операнда зависит от представления целых чисел реализацией.
  3. --x даёт 41, поэтому правая часть || не вычисляется. Сдвиг отрицательного y влево имеет неопределённое поведение; значение выражения и побочные эффекты в целом нельзя считать определёнными.
  4. Обе части && вычисляются: сначала y становится 1, затем 2. Значение выражения — 1; итог x = 42, y = 2.
  5. x++ даёт старое значение 42 и увеличивает x; --y даёт -106. Значение — -64; итог x = 43, y = -106.
  6. Оператор-запятая выполняет части слева направо: после первой части x = -63; вторая присваивает y = 42; последняя присваивает x = -105. Значение всего выражения — -105.
ВАЖНОДва изменения одной переменной в неупорядоченных частях выражения нельзя «разрешать» догадкой о порядке вычисления. Пользуйтесь правилами стандарта C, а не результатом одного запуска.
05

Переписать условие через switch

Задание. Перепишите фрагмент, используя единственный оператор switch. Дополнительные условные операторы использовать запрещено. 
if (i == -1)
    j = i;
else if (3 >= i && i >= 1)
    j = 10 - i;
else
    abort();
Подсказка switch сопоставляет значение с отдельными целочисленными константами, а не с диапазоном. Поэтому перечислите допустимые значения одного за другим; пустые метки case могут вести к общему присваиванию. Не забудьте остановить выполнение ветви после присваивания, иначе управление перейдёт к следующей метке.
Показать модельное решение на C 
#include <stdlib.h>

switch (i) {
case -1:
    j = i;
    break;
case 1:
case 2:
case 3:
    j = 10 - i;
    break;
default:
    abort();
}

Ветви case 1, case 2 и case 3 объединены, потому что используют одно присваивание. break не даёт перейти к default после успешного случая.

Проверьте: проследите ветви для i = -1, i = 2 и значения вне разрешённых случаев.

06

Найти все вхождения подстроки строки

Задание. Напишите функцию int count(const char *s), которая подсчитывает все вхождения подстроки "2012" в строке s. Например, для "28012012-пересдача" функция должна вернуть 1. Строка может состоять из любых символов и быть пустой или непустой. Размер требуемой функции памяти не должен зависеть от длины строки.
Подсказка Строка заканчивается на '\0'; при сравнении четырёх символов убедитесь, что справа достаточно символов. Если после совпадения сдвигать поиск сразу на четыре позиции, можно пропустить перекрывающиеся вхождения.
Показать модельное решение на C 
#include <string.h>

int count(const char *s)
{
    int total = 0;

    for (const char *p = s; *p != '\0'; ++p) {
        if (strncmp(p, "2012", 4) == 0) {
            ++total;
        }
    }

    return total;
}

Проверка начинается с каждой позиции, поэтому перекрывающиеся совпадения не теряются. Строки короче четырёх символов безопасно обрабатываются strncmp; для "2012012" функция вернёт 2.

Проверьте: пустую строку, строку короче образца, совпадение в самом конце и перекрывающиеся совпадения, например в "2012012".

07

Удалить слова, содержащие образец строки

Задание. Напишите функцию void erase(char *s, const char *w). Слово w — непустая строка из латинских букв. Строка s представляет собой последовательность слов, разделённых одним пробелом; перед первым словом и после последнего пробелов нет. Удалите из s все слова, в которые w входит как подстрока. Относительный порядок остальных слов должен сохраниться, а изменённая строка должна удовлетворять тем же ограничениям. Память под все временные массивы должна выделяться динамически и освобождаться в конце работы функции.
  1. Сначала для каждого слова определите начало и конец.
  2. Проверьте, содержит ли слово w как подстроку.
  3. Перенесите оставшиеся слова в новый буфер, сохраняя исходный порядок и разделители.
  4. Скопируйте итог обратно в s, добавьте '\0' и освободите всю динамически выделенную память.
Подсказка Выделите один временный буфер размером не меньше исходной строки плюс завершающий нулевой символ. Обходите исходную строку указателем чтения; для каждого слова временно завершайте его нулём, чтобы вызвать strstr, затем восстанавливайте разделитель. В буфер записывайте только оставшиеся слова и вставляйте пробел перед словом, если в буфере уже есть хотя бы одно. Проверьте удаление первого, среднего, последнего, всех слов и отсутствие удалений. Если выделение памяти не удалось, явно сообщите об ошибке и не изменяйте исходную строку.
Показать модельное решение на C 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

void erase(char *s, const char *w)
{
    size_t length = strlen(s);
    char *result = malloc(length + 1);
    if (result == NULL) {
        fputs("erase: allocation failed\n", stderr);
        return;
    }

    size_t read = 0;
    size_t write = 0;
    int kept_word = 0;

    while (read < length) {
        size_t start = read;
        while (read < length && s[read] != ' ') {
            ++read;
        }

        size_t word_length = read - start;
        char separator = s[read];
        s[read] = '\0';
        int remove_word = strstr(s + start, w) != NULL;
        s[read] = separator;

        if (!remove_word) {
            if (kept_word) {
                result[write++] = ' ';
            }
            memcpy(result + write, s + start, word_length);
            write += word_length;
            kept_word = 1;
        }

        if (read < length) {
            ++read;
        }
    }

    result[write] = '\0';
    memcpy(s, result, write + 1);
    free(result);
}

Единственный временный массив создаётся через malloc, а после копирования результата освобождается через free. При ошибке выделения функция сообщает об этом в stderr и оставляет s неизменной.

ГРАНИЧНЫЕ СЛУЧАИПри удалении всех слов результатом должна стать пустая строка "". При удалении последнего слова не оставляйте пробел в конце; при сохранении слова после удалённых не оставляйте пробел в начале.
08

Сопоставить элементы массива с двух концов вызов

Задание. Используя один или несколько циклов for, сформируйте для массива int a[N] сумму sum = Σ xᵢyᵢ, где xᵢ — i-й отрицательный элемент массива при просмотре от начала, а yᵢ — i-й положительный элемент при просмотре от конца. Положительных и отрицательных элементов в массиве одинаковое ненулевое количество. Операторы перехода и другие операторы циклов использовать запрещено.
Подсказка Ведите два независимых индекса: индекс отрицательных чисел увеличивается от нуля, индекс положительных уменьшается от N - 1. В каждом цикле for пропускайте нули и элементы неверного знака. Умножайте и продвигайте оба индекса только после того, как нашли очередную пару. Поддерживайте условия границ в заголовках циклов, чтобы не обращаться за пределы массива; не используйте while, break или continue.
Показать модельное решение на C 
long long sum = 0;
int ineg = 0;
int ipos = N - 1;

for (; ineg < N && ipos >= 0; ) {
    for (; ineg < N && a[ineg] >= 0; ++ineg) {
    }
    for (; ipos >= 0 && a[ipos] <= 0; --ipos) {
    }

    if (ineg < N && ipos >= 0) {
        sum += (long long)a[ineg] * a[ipos];
        ++ineg;
        --ipos;
    }
}

Внутренние циклы пропускают нули и элементы неверного знака. Внешний цикл использует только for, без break или continue. Предполагается, что требуемая сумма помещается в long long.

Проверьте: граничные позиции, нули между числами и отрицательные значения в начале и конце массива. Не читайте a[N] или a[-1].

09

Рекурсивно обойти дерево вызов

Задание. Для структуры ниже напишите void large_sons(struct tree *t), которая печатает в стандартный поток вывода ключи элементов дерева, у которых ключ больше ключа родителя. Корень дерева не проверяется. Дерево может быть пустым или непустым. Операторы циклов и переходов, глобальные и статические переменные использовать нельзя. 
struct tree {
    int key;
    struct tree *left;
    struct tree *right;
};
Подсказка Базовый случай — пустой указатель. Для каждого узла отдельно проверьте существующего левого и правого ребёнка, затем рекурсивно обработайте оба поддерева.
Показать модельное решение на C 
#include <stdio.h>

void large_sons(struct tree *t)
{
    if (t == NULL) {
        return;
    }

    if (t->left != NULL && t->left->key > t->key) {
        printf("%d\n", t->left->key);
    }
    if (t->right != NULL && t->right->key > t->key) {
        printf("%d\n", t->right->key);
    }

    large_sons(t->left);
    large_sons(t->right);
}

Для каждого узла сначала проверяются его дети, затем обходятся поддеревья. Проверка на NULL должна предшествовать чтению поля через указатель.

Проверьте: пустое дерево, один узел, ребёнка меньше родителя и ребёнка больше родителя.

10

Трассировать программу с указателями вызов

Задание. Что будет напечатано при выполнении программы? 
#include <stdio.h>

int x = 2, y = 1;
int a[3] = { 1, 2 };

int f(int x, int **p) {
    static int c = 2;

    if (c--)
        **p += x;
    else
        ++x;

    return (*p)++ - a - x;
}

int main(void) {
    int x = y, c = 0;
    int *p;
    p = &a[x];

    for (int y = 2; y >= c; --y, ++x)
        c = f(y, &p);

    printf("%d %d %d %d %d\n", a[0], a[1], a[2], x, y);
    return 0;
}
Подсказка Составьте таблицу для каждой итерации: значения локальных переменных, значение static c до и после вызова, индекс указателя p, содержимое массива и значение, возвращённое функцией. В строке (*p)++ постфиксный оператор применяется к выражению *p, которое имеет тип int *; следовательно, меняется сам указатель. Перед разыменованием проверяйте, что указатель указывает на элемент массива.
Показать модельное решение
ВызовАргументы (x, y)static cМассив после вызоваИтог pВозврат
1(2, 2)2 → 1[1, 4, 0]&a[2]-1
2(1, 1)1 → 0[1, 4, 1]&a[3] (за последним элементом)1

После второго вызова локальный счётчик цикла становится y = 0, а локальный x = 3; условие 0 >= 1 ложно. Внешняя y в main не изменялась и равна 1. Напечатанная строка: 1 4 1 3 1.

В выражении (*p)++ увеличивается сам указатель p, а не число по адресу. После последнего увеличения он указывает на допустимую позицию сразу за массивом; эта позиция не разыменовывается.

ПРОВЕРКАЕсли во время трассировки обнаружили выход за границы или неопределённое поведение, итог нельзя считать надёжным только потому, что один компилятор напечатал конкретные числа.

Короткая самопроверка

  • Я могу объяснить, сколько элементов или пар проверяет мой цикл.
