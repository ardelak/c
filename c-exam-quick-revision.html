ВОПРОС 01

Язык C и абстрактная машина

C — стандартизованный процедурный язык. Абстрактная машина C задаёт правила, по которым программа должна наблюдаемо работать; компилятор может выбирать любые преобразования, сохраняющие это поведение («as-if» rule).

Важно: неопределённое поведение не означает «один из возможных правильных результатов» — стандарт не задаёт требований к результату.

ВОПРОС 02

Структура программы на C

Обычная программа включает заголовки, объявления типов и функций, точку входа int main(void) и определения функций. Объявление сообщает компилятору тип и сигнатуру; определение содержит тело.

Прототип функции должен быть видим до её вызова. В многофайловой программе заголовок обычно содержит общие объявления, а исходные файлы — определения.

ВОПРОС 03

Типы, переменные, константы и классы памяти

Тип задаёт множество значений и допустимые операции. Объект имеет область видимости (где его имя доступно), время хранения (как долго существует объект) и, для идентификаторов с внешним/внутренним связыванием, linkage (какое объявление обозначает тот же объект).

  • К спецификаторам класса хранения относятся auto, register, static, extern и, начиная с C11, _Thread_local. Они не взаимозаменяемы с областью видимости.
  • Локальный объект обычно имеет автоматическое время хранения; static-объект существует всю программу.
  • extern обычно объявляет объект или функцию, определённые в другом месте; register не гарантирует размещение в регистре.
  • const запрещает изменять объект через это имя, но не всегда создаёт константное выражение для компилятора.

Не путайте: область видимости имени и время хранения объекта — разные свойства.

ВОПРОС 04

Целочисленные типы и арифметика

Целочисленное деление отбрасывает дробную часть в сторону нуля: 7 / 2 == 3, -7 / 2 == -3. Остаток согласован с таким делением: -7 % 2 == -1.

Беззнаковая арифметика выполняется по модулю диапазона типа. Переполнение знакового целого типа обычно приводит к неопределённому поведению; исключение — операции с unsigned.

Проверьте: деление на ноль и переполнение — не способы получить «особое» число; их поведение не определено.

ВОПРОС 05

Преобразование типов

В арифметических выражениях сначала выполняются целочисленные повышения, затем обычные арифметические преобразования приводят операнды к общему типу. Правило зависит от ранга, знаковости и диапазона типов.

  • Например, char и short обычно повышаются до int.
  • При смешении signed и unsigned внимательно определите общий тип до сравнения или вычисления.
  • Явное приведение меняет тип выражения, но не отменяет проверку диапазона и не исправляет переполнение, уже произошедшее до приведения.
ВОПРОС 06

Старшинство операций

Приоритет и ассоциативность определяют группировку: a + b * c означает a + (b * c). Скобки стоит добавлять, когда они улучшают ясность.

Приоритет — не порядок вычисления. Он не говорит, какой операнд будет вычислен первым. Изменять одну переменную в несогласованных, не упорядоченных друг относительно друга частях выражения опасно и может дать неопределённое поведение.

ВОПРОС 07

Операторы и составной оператор

  • if / else выбирает ветвь; в цепочке условий порядок проверок имеет значение.
  • switch выбирает ветвь по целочисленному значению; без break управление может перейти к следующей метке.
  • for, while, do while отличаются моментом проверки условия и способом записи шага цикла.
  • break завершает ближайший цикл или switch; continue переходит к следующей итерации; return завершает функцию; goto переходит к метке.
  • Блок { ... } группирует объявления и операторы и задаёт область видимости блочных имён.
ВОПРОС 08

Символьный тип char

char хранит один байт; его знаковость зависит от реализации. Символьная константа, например 'A', имеет тип int в C. Строковый литерал "A" содержит символ и завершающий '\0'.

Изменять строковый литерал нельзя. Для функций <ctype.h> передавайте EOF или значение, преобразованное к unsigned char.

ВОПРОС 09

Массивы и строки

Элементы массива расположены последовательно. Массив из N символов для текста длины N должен иметь место ещё и для нулевого терминатора.

strlen(s) считает символы до '\0'; sizeof array даёт размер массива в байтах только там, где имя ещё обозначает сам массив. Сравнивайте строки через strcmp, а не ==.

После передачи массива в функцию параметр-массив становится указателем; длину обычно нужно передавать отдельно.

ВОПРОС 10

Указатели, адресная арифметика и преобразование

&x получает адрес объекта, *p обращается к объекту по адресу. Указатель должен быть корректно инициализирован до чтения или записи через него.

Арифметика указателей разрешена внутри одного массива и может дать указатель на позицию сразу за последним элементом; разыменовывать эту позицию нельзя. Указатель на объект можно преобразовать в void * и обратно; преобразование произвольных указателей не исправляет выравнивание, время жизни или тип объекта.

ВОПРОС 11

Указатели и массивы; массивы указателей; многомерные массивы

В большинстве выражений имя массива преобразуется в указатель на первый элемент, но массив и указатель — разные типы. Например, int *p[4] — массив указателей, а int (*p)[4] — указатель на массив из четырёх int.

Для int a[R][C] строка — массив из C целых, а преобразование a даёт указатель на строку: int (*)[C], не int **.

ВОПРОС 12

Объявление функции и параметры

Объявление функции сообщает возвращаемый тип, имя и типы параметров, например int max(int a, int b);. Формальные параметры — имена в объявлении/определении; фактические аргументы — выражения при вызове.

Возвращаемое значение передаёт результат вызывающему коду. Функция с типом void не возвращает значение; это не то же самое, что функция без параметров (f(void)).

ВОПРОС 13

Определения, вызовы и передача параметров

C передаёт аргументы по значению. Если параметр — указатель, копируется адрес: функция может изменить объект по этому адресу, но переназначение локальной копии указателя само по себе не меняет указатель вызывающего кода.

Параметр, записанный как int a[], корректируется к int *a. Квалификатор restrict — обещание вызывающего кода об отсутствии конфликтующего доступа через другие указатели в течение заданного периода; нарушение обещания может привести к неопределённому поведению.

ВОПРОС 14

Рекурсия и inline

Рекурсивная функция вызывает себя прямо или косвенно. Для завершения нужны базовый случай и шаг, который приближает вход к нему; каждый вызов имеет собственные параметры и автоматические локальные объекты. Чрезмерная глубина рекурсии может исчерпать доступные ресурсы стека.

inline — рекомендация/свойство определения для правил связывания, а не гарантия, что компилятор физически встроит вызов.

ВОПРОС 15

Операция sizeof

sizeof возвращает размер объекта или типа в байтах, результат имеет тип size_t. Для массива в той же области вычисления можно получить число элементов как sizeof a / sizeof a[0].

В функции параметр-массив уже является указателем, поэтому sizeof параметра возвращает размер указателя, а не исходного массива. Для структуры размер может включать байты выравнивания.

ВОПРОС 16

Вещественная арифметика

float и double представляют лишь ограниченное число двоичных значащих цифр; многие десятичные дроби хранятся приближённо. Сравнение вещественных результатов на точное равенство часто ненадёжно.

Чтобы получить дробное деление, преобразуйте операнд до деления: (double)a / b. Приведение уже полученного a / b не восстановит отброшенную дробную часть.

ВОПРОС 17

Отношения, логика, биты и множество

Операции сравнения и логические !, &&, || дают 0 или 1; && и || используют короткое замыкание. Побитовые &, |, ^, ~ работают с битами целых чисел и не выполняют короткого замыкания.

Множество элементов конечного универсального набора можно кодировать битовой маской: бит i означает принадлежность элемента i; объединение — A | B, пересечение — A & B, разность — A & ~B & U, где U — маска допустимого универсального набора.

Перед сдвигом проверьте ширину типа и допустимость счётчика сдвига; не сдвигайте знаковое значение в область неопределённого поведения.

ВОПРОС 18

Структуры, перечисления, объединения и битовые поля

  • struct хранит все поля одновременно; доступ к полю через объект — ., через указатель — ->.
  • union размещает поля в общей области памяти; обычно осмысленно использовать значение последнего записанного поля.
  • enum задаёт именованные целочисленные константы.
  • Битовые поля упаковывают заданное число бит в структуре, но расположение и некоторые свойства зависят от реализации; взять адрес битового поля нельзя.
ВОПРОС 19

Динамическое распределение памяти

malloc выделяет неинициализированную область, calloc выделяет память и заполняет её нулевыми байтами, realloc меняет размер, free освобождает блок. Нулевые байты не обязаны быть представлением нулевого значения для любого типа.

Проверяйте результат выделения; вычисляйте размер через sizeof *p. Для realloc используйте временный указатель, чтобы не потерять старый блок при ошибке. После free не используйте указатель и не освобождайте блок повторно.

ВОПРОС 20

Указатель на функцию

Указатель на функцию хранит адрес функции совместимого типа и позволяет передать поведение как параметр (callback). Скобки важны: int (*cmp)(const void *, const void *) — указатель на функцию, а без скобок декларация означает другое.

Вызов возможен как cmp(a, b); аргументы и возвращаемый тип должны соответствовать сигнатуре.

ВОПРОС 21

Сборка и препроцессор

Типичный путь: препроцессор обрабатывает директивы; компилятор переводит C в ассемблер/объектный код; ассемблер создаёт объектный файл; компоновщик объединяет объектные файлы и библиотеки в исполняемый файл.

#include подключает содержимое заголовка; include guards предотвращают повторную обработку заголовка. Условная компиляция использует #if, #ifdef, #ifndef и #endif.

Объявление функции без определения может успешно пройти компиляцию исходного файла, но привести к ошибке компоновки.

ВОПРОС 22

Стандартные библиотеки C

Подключайте заголовок, где объявлена нужная функция: <stdio.h> — ввод/вывод, <stdlib.h> — память и общие утилиты, <string.h> — строки/память, <ctype.h> — классификация символов, <math.h> — математические функции. Для <ctype.h> передавайте EOF или значение типа unsigned char.

Полезны также <stdint.h> для целых заданной ширины, <limits.h> и <float.h> для диапазонов типов, <assert.h> для проверок предположений в отладке.

Финальная проверка

Сможете ли вы без шпаргалки объяснить разницу между объявлением и определением, массивом и указателем, областью видимости и временем хранения, логическими и побитовыми операциями, компиляцией и компоновкой?

Для любой короткой программы также проверьте: какие типы у выражений, где меняются объекты, соблюдены ли границы массива и определено ли поведение по стандарту C.
