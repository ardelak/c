Задача 7: Проверка фразы на палиндром

Метод двух встречных указателей с фильтрацией символов через <ctype.h>.

Задача 7: Проверка фразы на палиндром с игнорированием пробелов и знаков препинания.
Напишите функцию int is_palindrome(const char *s), которая возвращает 1, если строка читается одинаково слева направо и справа налево (игнорируя регистр букв, пробелы и любые знаки препинания), и 0 в противном случае.
Пример: "Madam, I'm Adam!" → 1 (палиндром). Используйте два встречных указателя, isalnum и tolower.

Краткий разбор: что нужно сделать по шагам

  1. Проверить входной указатель: если передан NULL, сразу вернуть 0. Если строка пустая (первый же символ равен '\0'), вернуть 1 (пустая строка считается палиндромом).
  2. Поставить два указателя на края строки: левый указатель left ставим на начало строки (s), а правый right — на последний значащий символ перед '\0' (сначала находим длину через strlen(s) или двигаем right до '\0' и делаем шаг назад right--).
  3. Запустить цикл навстречу друг другу (while (left < right)): пока указатели не встретились, мы должны сравнивать только буквы и цифры.
  4. Пропустить «мусор» слева и справа:
    • Если *left не буква и не цифра (!isalnum((unsigned char)*left)), сдвигаем left++.
    • Если *right не буква и не цифра (!isalnum((unsigned char)*right)), сдвигаем right--.
    • В обоих внутренних циклах обязательно следим за условием left < right, чтобы указатели не перескочили друг через друга и не вышли за границы строки.
  5. Сравнить символы без учёта регистра: переводим оба символа в нижний регистр через tolower((unsigned char)*left) и tolower((unsigned char)*right). Если они не равны — сразу возвращаем 0.
  6. Сдвинуть оба указателя внутрь: после успешного совпадения пары делаем шаг left++ и right--. Если внешний цикл завершился без ошибок — возвращаем 1.

ЛОВУШКА НА ЗАЧЕТЕНикогда не забывайте сдвигать указатели left++ и right-- в самом конце итерации после сравнения if (tolower(...) != tolower(...))! Если этого не сделать, указатели останутся стоять на первой же совпавшей паре букв (например, 'M' и 'm'), и программа зависнет в бесконечном цикле.

Задача 8: Подсчёт слов и поиск самого длинного слова

Анализ строки за один проход без модификации текста и вывод среза через %.*s.

Задача 8: Подсчёт слов и поиск самого длинного слова без изменения строки.
Словом считается непрерывная последовательность непробельных символов (!isspace). Напишите функцию:
int analyze_words(const char *s, const char **longest_start, int *longest_len)
которая не изменяет строку s (не использует strtok!), возвращает общее число слов, по адресу longest_start записывает указатель на первую букву самого длинного слова в s, а по адресу longest_len — его длину. Выведите найденное слово в main с помощью спецификатора точной ширины printf("%.*s", len, ptr)!

Краткий разбор: что нужно сделать по шагам

  1. Разобраться с выходными параметрами: функция должна вернуть сразу три результата:
    • Общее количество слов — через обычный return total_words;.
    • Длину самого длинного слова — через указатель на число int *longest_len (записываем как *longest_len = ...).
    • Адрес первой буквы самого длинного слова — через указатель на указатель const char **longest_start (в main у нас есть переменная-указатель const char *word_ptr, и мы передаём в функцию её адрес &word_ptr, чтобы функция изменила сам указатель через *longest_start = ...).
  2. Инициализировать значения по умолчанию: обнулить *longest_start = NULL и *longest_len = 0 на случай, если в строке вообще нет слов.
  3. Пройти по строке указателем p в цикле while (*p != '\0'):
    • Сначала пропускаем все пробельные символы: пока *p != '\0' && isspace((unsigned char)*p), делаем p++.
    • Если после пропуска пробелов мы упёрлись в '\0' — строка закончилась, выходим из цикла (break).
    • Иначе мы стоим ровно на первой букве нового слова! Увеличиваем счётчик слов word_count++ и запоминаем адрес начала этого слова: const char *word_begin = p;.
    • Теперь бежим до конца текущего слова: пока *p != '\0' && !isspace((unsigned char)*p), двигаем p++.
    • Когда цикл остановился, указатель p стоит сразу за последней буквой слова. Вычисляем длину слова через разность указателей: int current_len = (int)(p - word_begin);.
    • Если current_len > *longest_len, обновляем рекорд: сохраняем *longest_len = current_len и *longest_start = word_begin.
  4. Вывести найденное слово в main без изменения строки: поскольку после слова в исходной строке идёт пробел (а не '\0'), обычный printf("%s", ptr) распечатал бы весь остаток строки до конца. Поэтому используем спецификатор "%.*s", который печатает ровно len символов начиная с адреса ptr.

ЗАПОМНИТЕПочему в условии запрещена функция strtok()? Потому что strtok() разрушает исходную строку, заменяя пробелы на нулевые байты '\0', и не может работать с константными строками const char *. Наш алгоритм с указателями оставляет строку в полной неприкосновенности.

Задача 9: Нормализация (сжатие) пробелов на месте

Два попутных указателя (read и write) для фильтрации строки за O(n) времени и O(1) памяти.

Задача 9: Нормализация (сжатие) пробелов в строке на месте.
Напишите функцию void normalize_spaces(char *s), которая за O(n) времени и O(1) памяти:
1. Удаляет все пробелы в начале строки.
2. Удаляет все пробелы в конце строки.
3. Между соседними словами оставляет ровно по одному пробелу ' '.
Пример: " Hello from MSU " → "Hello from MSU".

Краткий разбор: что нужно сделать по шагам

В Задаче 4 на прошлом занятии ты уже использовал метод двух указателей (читающий read_p и пишущий write_p) для удаления цифр из строки. Здесь идея точно такая же! Так как мы только удаляем лишние пробелы, пишущий указатель write_p никогда не обгонит читающий read_p, и мы ничего случайно не затрём.

  1. Завести два указателя на начало массива s:
    • const char *read_p = s; — бежит вперёд и просматривает каждый символ исходной строки.
    • char *write_p = s; — указывает на позицию, куда нужно записать следующий «чистый» символ.
  2. Завести флаг состояния int in_word = 0;: он равен 1, когда read_p идёт внутри слова, и сбрасывается в 0, как только read_p встречает пробел.
  3. Пробежать циклом while (*read_p != '\0'):
    • Если символ пробельный (isspace((unsigned char)*read_p)): мы его не копируем! Просто сбрасываем флаг in_word = 0 (слово закончилось). За счёт этого все ведущие и хвостовые пробелы игнорируются автоматически!
    • Если символ НЕ пробельный (мы встретили букву/цифру/знак):
      • Проверяем: если это первая буква нового слова (in_word == 0) И мы уже записали в буфер хотя бы одно слово раньше (write_p != s), то перед этим новым словом мы обязаны поставить ровно один пробел: *write_p = ' '; write_p++;.
      • Затем копируем сам символ: *write_p = *read_p; write_p++; и поднимаем флаг in_word = 1;.
    • На каждом шаге двигаем читающий указатель: read_p++.
  4. Поставить нуль-терминатор в конце: когда цикл закончился, записываем *write_p = '\0';, чтобы отрезать «старый хвост» строки.

Требование задачиПочему оно выполняется само собой
1. Удаление пробелов в начале Пока в начале строки идут пробелы, условие !isspace(*read_p) ложно, и write_p стоит на самом первом байте s. Когда встречается первая буква первого слова, условие write_p != s ложно, поэтому перед первым словом пробел не ставится.
2. Удаление пробелов в конце Мы никогда не пишем пробел в момент, когда видим пробел! Мы пишем пробел только перед первой буквой следующего слова. Если после последнего слова идут пробелы до самого '\0', нового слова не наступит, и сразу после последнего слова встанет *write_p = '\0'.
3. Ровно один пробел между словами Сколько бы пробелов или табуляций ни шло подряд между словами (хоть 1, хоть 100), все они лишь сбрасывают in_word = 0. А когда начинается следующее слово, блок if (in_word == 0 && write_p != s) срабатывает ровно один раз и вставляет один символ ' '.
СОВЕТ ДЛЯ ЗАЧЕТАОбрати внимание: если в строке между словами была табуляция '\t', мы всё равно записываем обычный пробел *write_p = ' ' (а не *read_p), потому что условие требует оставить между словами именно символ пробела ' '.

Задача 10: Собственный парсер целого числа (parse_int)

Посимвольный перевод строки в число с учётом знака и проверкой ошибок.

Задача 10: Собственный парсер целого числа из строки (my_atoi с контролем ошибок).
Напишите функцию int parse_int(const char *s, int *out_value), которая переводит строку в целое число без использования библиотечных atoi / sscanf:
1. Пропускает ведущие пробелы (isspace).
2. Учитывает необязательный знак '+' или '-'.
3. Читает подряд идущие цифры, накапливая число по формуле res = res * 10 + (*p - '0').
4. Если в строке не было ни одной цифры, возвращает код ошибки -1; иначе записывает ответ в *out_value и возвращает 0.

Краткий разбор: что нужно сделать по шагам

Стандартная библиотечная функция atoi("abc") возвращает 0, и невозможно понять — то ли в строке реально был написан "0", то ли произошла ошибка! Поэтому на зачётах просят написать безопасный парсер, который возвращает код ошибки (0 — успех, -1 — ошибка), а само число отдаёт через указатель int *out_value.

  1. Проверить входные указатели: если s == NULL или out_value == NULL, вернуть код ошибки -1.
  2. Шаг 1 — Пропустить ведущие пробелы: двигать указатель p вперёд, пока *p != '\0' && isspace((unsigned char)*p).
  3. Шаг 2 — Проверить знак числа: завести переменную int sign = 1;.
    • Если *p == '-', ставим sign = -1; и сдвигаем указатель на следующий символ (p++).
    • Иначе если *p == '+', оставляем sign = 1; и тоже сдвигаем указатель (p++).
  4. Шаг 3 — Прочитать подряд идущие цифры и накопить результат:
    • Заводим аккумулятор int res = 0; и флаг/счётчик прочитанных цифр int has_digits = 0;.
    • Пока текущий символ — цифра (isdigit((unsigned char)*p)):
      • Отмечаем, что встретили хотя бы одну цифру: has_digits = 1;.
      • Превращаем символ цифры в число вычитанием кода нуля (*p - '0') и приписываем справа к результату: res = res * 10 + (*p - '0');.
      • Сдвигаем указатель: p++.
  5. Шаг 4 — Проверить, была ли прочитана хотя бы одна цифра: если has_digits == 0 (например, строка была пустой, содержала только " - " или "abc"), возвращаем -1. Иначе записываем *out_value = res * sign; и возвращаем 0.
