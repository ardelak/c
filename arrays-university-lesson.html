01

Сортировка массива по возрастанию

Два вложенных цикла сравнивают элементы и меняют их местами.

Условие. Прочитать из input.txt длину N и N целых чисел. Отсортировать массив по возрастанию, вывести его в output.txt. При некорректных данных завершить программу с кодом -1.

Идея алгоритма

Для каждой позиции i рассматриваем все элементы правее неё. Если находим элемент меньше a[i], меняем эти два значения. После завершения прохода с данным i в позиции i стоит наименьший элемент из ещё не упорядоченной части массива.

ШагСравнениеМассив после шагаСмысл
Старт—[1, 2, 1]Массив из примера.
i=0, j=11 > 2 — нет[1, 2, 1]Обмен не выполняется.
i=0, j=21 > 1 — нет[1, 2, 1]Равные значения не меняются местами.
i=1, j=22 > 1[1, 1, 2]Значения меняются местами; сортировка завершена.

Входные данные: 3, 1, 2, 1. Ожидаемый результат: 1 1 2.

Полная программа из файла с заданиями

#include <stdio.h>
#include <stdlib.h> // Подключение stdlib для malloc

void sort (int *a, int n);

int main(void)
{
    FILE* fin;
    FILE* fout;
    int* a;  // Описание имени массива
    int n;   	// переменная для записи длины массива
    int i;   	// переменная для перебора элементов в цикле for
    int q = 1;  // переменная для проверки некорректных данных
    
    int ret = 0; 
    
    fin = fopen("input.txt", "r");
    fout = fopen("output.txt","w");
    
    if ((fscanf(fin, "%d", &n) != EOF) && n > 0) 	// чтение размера массива
    {
        a = (int*)malloc(n*sizeof(int));     // выделение памяти для массива
        
        for (i = 0; i < n; i++)                     //чтение массива
            q = fscanf(fin, "%d", &a[i]);
        
        if (q == 1)
        {
            sort(a, n);                             // вызов функции для обработки массива
            
            for (i = 0; i < n; i++)                 // вывод массива
                fprintf(fout, "%d ", a[i]);
        }
        else
        {
            ret = -1; 
        }
        
        free(a);                                   //очистка памяти, выделенной под массив
    }
    else
    {
        ret = -1; 
    }
    
    fclose(fin); 
    fclose(fout);
    
    return ret;
}

// Обработка массива a из n элементов
void sort (int *a, int n)
{
int i, j, temp;
    for (i = 0; i < n-1; i++) {
        for (j = i+1; j < n; j++) { 
           if (a[i] > a[j]) {
             temp = a[i];
             a[i] = a[j];
             a[j] = temp;
           }
        }
    }
}

Как рассказать про функцию sort

  1. int *a — адрес первого элемента; n — длина массива. Функции не нужна копия всех чисел.
  2. Внешний цикл выбирает текущую позицию i. Последняя позиция отдельно не выбирается: если всё до неё уже упорядочено, последний элемент автоматически окажется на месте.
  3. Внутренний цикл перебирает элементы справа, начиная с i + 1.
  4. Условие a[i] > a[j] обнаруживает пару в неправильном порядке. Переменная temp временно сохраняет одно значение, чтобы при обмене его не потерять.
  5. В результате на каждой позиции последовательно закрепляется минимум оставшейся части. Два вложенных цикла дают квадратичное число сравнений: порядок роста O(n²).
ПРОВЕРКАВ примере N = 3; функция sort переставляет считанные значения [1, 2, 1], после чего цикл вывода записывает 1 1 2.
02

Последовательные (префиксные) суммы

Каждый элемент заменяется суммой всех значений от начала массива до его позиции.

Условие. Прочитать массив вещественных чисел и записать в тот же массив последовательные суммы.

Что значит «последовательные суммы»

Результат в позиции i — сумма исходных элементов от a[0] до a[i]: a[0] + a[1] + ... + a[i]. Поэтому в цикле начиная с индекса 1 к текущему элементу прибавляется уже накопленная сумма слева.

Перед шагомДействиеПосле шага
[2, 1, 0]a[1] = 1 + a[0] = 3[2, 3, 0]
[2, 3, 0]a[2] = 0 + a[1] = 3[2, 3, 3]

Входные данные: 3, 2, 1, 0. Ожидаемый результат: 2.000000 3.000000 3.000000.

Хотя массив изменяется «на месте», нужное исходное значение не теряется: к моменту обработки i ячейка a[i] ещё содержит своё исходное значение, а a[i - 1] уже содержит сумму предыдущего префикса.

Полная программа из файла с заданиями

#include <stdio.h>
#include <stdlib.h> // Подключение stdlib для malloc

void f (double *a, int n);

int main(void)
{
    FILE* fin;
    FILE* fout;
    double* a;  // Описание имени массива
    int n;   	// переменная для записи длины массива
    int i;   	// переменная для перебора элементов в цикле for
    int q = 1;  // переменная для проверки некорректных данных
    
    int ret = 0; 
    
    fin = fopen("input.txt", "r");
    fout = fopen("output.txt","w");
    
    if ((fscanf(fin, "%d", &n) != EOF) && n > 0) 	// чтение размера массива
    {
        a = (double*)malloc(n*sizeof(double));     // выделение памяти для массива
        
        for (i = 0; i < n; i++)                     //чтение массива
            q = fscanf(fin, "%lf", &a[i]);
        
        if (q == 1)
        {
            f(a, n);                                // вызов функции для обработки массива
            
            for (i = 0; i < n; i++)                 // вывод массива
                fprintf(fout,"%lf ", a[i]);
        }
        else
        {
            ret = -1; 
        }
        
        free(a);                                   //очистка памяти, выделенной под массив
    }
    else
    {
        ret = -1; 
    }
    
    fclose(fin); 
    fclose(fout);
    
    return ret;
}

// Обработка массива a из n элементов
void f (double *a, int n)
{
   int i;
   for(i = 1; i < n; i++){
       a[i] += a[i-1];
   }
}

Разбор функции f

  • Тип double * означает, что функция получает массив вещественных чисел. В main функция вызывается как f(a, n).
  • Цикл начинается с i = 1, потому что первый префикс состоит только из a[0] и уже является правильным.
  • a[i] += a[i - 1] — сокращённая запись a[i] = a[i] + a[i - 1]. Слева записывается новый префикс, справа берётся предыдущий.
  • После завершения цикла все ячейки массива содержат префиксные суммы. При n == 1 тело цикла не выполняется и единственное число остаётся без изменения.
НЕ ПУТАТЬЭто не сумма всех элементов, записанная в одну переменную. Программа сохраняет отдельную накопленную сумму для каждого префикса.
03

Коэффициенты производной многочлена

Умножаем каждый коэффициент на исходную степень; формат вывода сохраняет N ячеек и ноль в позиции 0.

Условие. Массив A длины N хранит коэффициенты многочлена A[0] + A[1]x + A[2]x² + .... Записать в тот же массив коэффициенты производной.

Математика прежде кода

Производная слагаемого A[k]xk равна k · A[k] · xk-1. Значение коэффициента нужно умножить на его исходную степень. В примере задания результат сохраняет исходную длину N: в ячейке 0 стоит ноль, а начиная с ячейки 1 записаны коэффициенты производной. Поэтому массив результата имеет вид [0, A[1], 2·A[2], ...].

Индекс iИсходное значениеДействиеЗначение после шага
01a[0] *= 00
12a[1] *= 12
23a[2] *= 26

Для входа из условия [1, 2, 3] многочлен равен 1 + 2x + 3x², а его производная — 2 + 6x. По заданному формату, сохраняющему N ячеек, файл должен содержать 0.000000 2.000000 6.000000.

ВАЖНО ПРО ПРЕДСТАВЛЕНИЕЕсли коэффициенты производной хранить в обычном формате, где индекс совпадает со степенью x, результат был бы [2, 6] и длина — N - 1. Но приведённый в условии пример требует N чисел с нулём в начале. Ниже реализован именно формат примера: исходный индекс i сохраняется, а позиция 0 служит нулевой ячейкой.

Полная программа из файла с заданиями

Входные данные: 3, 1, 2, 3. Ожидаемый результат: 0.000000 2.000000 6.000000.

#include <stdio.h>
#include <stdlib.h> // Подключение stdlib для malloc

void f (double *a, int n);

int main(void)
{
    FILE* fin;
    FILE* fout;
    double* a;  // Описание имени массива
    int n;   	// переменная для записи длины массива
    int i;   	// переменная для перебора элементов в цикле for
    int q = 1;  // переменная для проверки некорректных данных

    int ret = 0;

    fin = fopen("input.txt", "r");
    fout = fopen("output.txt","w");

    if ((fscanf(fin, "%d", &n) != EOF) && n > 0) 	// чтение размера массива
    {
        a = (double*)malloc(n*sizeof(double));     // выделение памяти для массива

        for (i = 0; i < n; i++)                     //чтение массива
            q = fscanf(fin, "%lf", &a[i]);

        if (q == 1)
        {
            f(a, n);                                // вызов функции для обработки массива

            for (i = 0; i < n; i++)                 // вывод массива
                fprintf(fout,"%lf ", a[i]);
        }
        else
        {
            ret = -1;
        }

        free(a);                                   //очистка памяти, выделенной под массив
    }
    else
    {
        ret = -1;
    }

    fclose(fin);
    fclose(fout);

    return ret;
}
void f(double* a, int n){
for(int i = 0 ; i < n; i++){
        a[i] *= i;
}
}

Пошаговое объяснение функции

  1. В функции f цикл проходит все индексы от 0 до n - 1, то есть обрабатывает ровно N ячеек.
  2. Выражение a[i] *= i эквивалентно a[i] = a[i] * i. Индекс i — степень исходного члена, поэтому значение коэффициента умножается на эту степень.
  3. При i == 0 ячейка становится нулём: производная постоянного слагаемого равна нулю.
  4. Для входа [1, 2, 3] преобразования будут: a[0] = 1·0 = 0, a[1] = 2·1 = 2, a[2] = 3·2 = 6.
  5. Цикл меняет массив на месте; затем main выводит все N значений — это соответствует приведённому примеру.
ТОЧНОСТЬ ФОРМУЛИРОВКИМатематически 2 + 6x в стандартном представлении имеет коэффициенты [2, 6]. Ожидаемые [0, 2, 6] — это формат задания со сдвигом на одну позицию и нулём в ячейке 0. При защите решения объясните именно это соглашение: оно следует из примера и исходной функции a[i] *= i, хотя формулировка «массив коэффициентов производной» сама по себе может навести на компактный формат.

Как объяснить общую часть программ

  • FILE* fin и FILE* fout — указатели на входной и выходной файлы. fopen открывает файлы с именами input.txt и output.txt.
  • a — указатель на динамически выделенный массив; тип его элементов совпадает с задачей: int для сортировки и double для двух остальных вычислений.
  • n хранит длину массива, i используется как индекс в циклах, а q сохраняет результат последнего чтения элемента через fscanf.
  • ret изначально равен 0. В ветках, где программа обнаруживает некорректный размер или неуспешное чтение массива, ему присваивается -1; затем это значение возвращается из main.
  • После обработки free(a) освобождает массив, а два вызова fclose закрывают входной и выходной файлы.
  • В приведённых примерах каждый результат соответствует формату задачи: целые числа выводятся через %d, вещественные — через %lf, элементы отделяются пробелом.

Самопроверка перед ответом у доски

  • Могу показать, какие индексы меняются на каждой итерации.
  • Могу объяснить, почему границы циклов не дают обратиться за пределы массива.
  • Могу вручную вычислить результат на коротком массиве.
  • Различаю содержимое исходного массива и его содержимое после изменения «на месте».
  • Для производной могу вывести правило A[k]x^k → k·A[k]x^(k-1) и объяснить, почему по примеру выводятся N чисел, начиная с нуля.
  • Могу объяснить роль fin, fout, a, n, q и ret именно в данных программах.
